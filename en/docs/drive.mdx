## All files

The All files view in Drive compiles every file across all folders and subfolders in one place. It is particularly useful for performing bulk operations — Move, Copy, Add tags, Download, and Remove — across multiple files simultaneously. Rename is also available in this toolbar, but only when exactly one file is selected.

To access All files, navigate to Drive in the left navigation bar, then click All files in the left navigation pane.

The following options are available on the All files page:

- **Storage used** — View the used and total available storage. Select Buy more to purchase additional storage if needed.
- **Grid view** — Switch between list view (default) and grid view.
- **Filter** — Narrow files by Dependencies, Uploaded date, Uploaded by, Type, or Tags.

## FAQ

<Expandable title="Does moving a file break the image links in my articles?">
  No. Moving a file between Drive folders does not change its CDN URL. Any article that references the file continues to display it correctly after the move.
</Expandable>

<Expandable title="Does renaming a file break the image links in my articles?">
  No. Renaming a file does not change its CDN URL. Any article, page, or content reuse block that references the file continues to display it correctly after the rename.
</Expandable>

<Expandable title="What is the difference between Move and Copy in Drive?">
  Move relocates the original file to a new folder while preserving its URL. Copy creates a duplicate in a destination folder and assigns the duplicate a new URL. Use Move when you want to reorganize without affecting article links. Use Copy when you need the same file in multiple locations.
</Expandable>

<Expandable title="Can I recover a deleted file?">
  Yes, if you act within 30 days. Deleted files go to the Recycle bin and are permanently deleted after 30 days. To restore a file, go to **Drive > Recycle bin** and select **Restore**. If a file with the same name already exists, Document360 automatically appends a number to the restored file's name to avoid a conflict. Note that restoring a file does not automatically repair broken links in articles — you will need to re-embed the file in any affected articles.
</Expandable>

<Expandable title="What happens if I replace a file?">
  The existing file content is permanently overwritten by the new file. The CDN URL and file name remain unchanged, so all articles that reference the file will display the new content within 1 hour. The old file content cannot be restored — it is not sent to the Recycle bin. Always keep an offline backup before replacing a file.
</Expandable>

<Expandable title="What file types can I upload to Drive?">
  By default, all media formats are allowed. Your Owner or Admin can restrict allowed formats under **Settings** > **Knowledge base portal** > **General** > **Drive settings**.
</Expandable>
