After recording an interactive video in the **Editor**, it opens automatically in the **Interactive video editor** so you can enhance it before inserting it into your article. You can also reopen the editor anytime by selecting the demo in the article and clicking **Edit**, or by clicking the demo's title in [Document360 Engage](https://docs.document360.com/help/docs/document360-engage) and clicking **Edit**.

If you haven't recorded a demo yet, see [Recording interactive demo](https://docs.document360.com/help/docs/recording-interactive-demo).

---

## What you can do in the Interactive video editor

Each tool in the editor is covered in detail in its own article, to learn more about each tool click the links below.

- [Call to action](https://docs.document360.com/help/docs/call-to-action) \- Add buttons that link to URLs or display messages during playback
- [Hotspots](https://docs.document360.com/help/docs/hotspot-1) \- Add guided tooltips at click points to walk readers through each step
- [Blur](https://docs.document360.com/help/docs/blur-md) \- Mask credentials, PII, or sensitive UI elements at specific timestamps
- [Spotlight](https://docs.document360.com/help/docs/spotlight-1) \- Draw attention to key areas of the screen during playback
- [Highlight](https://docs.document360.com/help/docs/highlight-1) \- Emphasize specific elements with a color overlay at set time ranges
- [Image](https://docs.document360.com/help/docs/image-1) \- Insert images or emojis into the demo at specific timestamps
- [Text](https://docs.document360.com/help/docs/text-1) \- Add text overlays to annotate or label parts of the recording
- [Camera](https://docs.document360.com/help/docs/camera) \- Overlay a camera recording on top of the demo
- [Crop](https://docs.document360.com/help/docs/crop-1) \- Resize and reframe the demo to fit your article layout
- [Trim](https://docs.document360.com/help/docs/trim-1) \- Cut unwanted sections from the start, middle, or end
- [Music](https://docs.document360.com/help/docs/music-1) \- Add background music with fade in/out and pause on interaction options
- [Voice](https://docs.document360.com/help/docs/voice-1) \- Add AI voiceover in multiple languages or enable auto-generated subtitles
- [Annotation](https://docs.document360.com/help/docs/annotation) \- Add contextual notes, insights, announcements, or alerts at specific timestamps
- [Zoom](https://docs.document360.com/help/docs/zoom) \- Magnify a selected area of the screen at specific timestamps to focus attention on fine detail

## Create the demo in other languages

If your knowledge base serves readers in more than one language, you can create a version of the demo for each language from the same recording. You don't need to record the demo again.

The following elements can have different content in each language:

- Call to action
- Hotspot title and description
- Text
- Subtitles
- AI voiceover, which is generated in the language of the script

Visual elements such as blur, spotlight, highlight, crop, and trim stay the same across all language versions.

To create a language version, translate the demo from Document360 Engage. For the steps, see [Translate content](https://docs.document360.com/help/docs/document360-engage#translate-content).

To refine a translated version, click the demo's title in Document360 Engage, select the language from the **Language** dropdown in the preview, and click **Edit**. Then edit the call to action, hotspots, text, or subtitles for that language. The AI voiceover is generated from the translated text in the same language.

Readers see the version that matches the language they select on the knowledge base site. If the demo isn't translated into that language, readers see the default language version.

## Managing added elements

In the **Added elements** section, you can view all elements applied to the demo:

- Click **Edit** () to modify an element
- Click **Delete** () to remove it

Click **Close** to save all changes.

## FAQ

<Expandable title="Will articles with an interactive video appear in portal search results?">
  Yes. Articles containing an interactive video appear in portal search results if there is a match in the article title or content.
</Expandable>

<Expandable title="Do I need to record a separate demo for each language?">
  No. Translate the demo from Document360 Engage to create a version for each language from the same recording. For more information, see [Create the demo in other languages](/en/docs/editing-interactive-demo#create-the-demo-in-other-languages).
</Expandable>
