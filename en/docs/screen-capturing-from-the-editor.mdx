Document360's screen capture feature lets you capture screens directly from the editor without switching tools. You can capture an entire tab or a specific window, and all captures are automatically saved to **Drive** for reuse across articles.

These steps apply to the Advanced WYSIWYG editor and the unified Editor. The `/Screen capture` slash command works the same way in both.

 NOTE

The unified Editor is currently available for newly created projects. Projects created earlier continue to use the Advanced WYSIWYG editor and the Markdown editor.

---

## Before you begin

The screen capture feature requires the Document360 AI Capture extension. The extension only needs to be installed once and is supported on Google Chrome, Microsoft Edge, and Brave.

---

## How to capture a screen from the editor

1. Use the slash command `/Screen capture` and press **Enter**.
2. If you have not installed the **Document360 AI Capture** extension, click **Install** and follow the on-screen steps to complete the installation.

    NOTE

   For browser-specific installation steps, see [Installing the Document360 AI Capture extension](https://docs.document360.com/help/docs/install-document360-ai-capture-extension).
3. Once installed, return to the Knowledge base portal.
4. Select the desired screen to capture:

   - **Browser tab**: Captures only the selected browser tab.
   - **Window**: Captures only the selected window.
5. Click **Share** to proceed.

### If you selected a browser tab

1. The selected browser tab displays a message confirming that the tab is being shared with the Knowledge base portal. Click **Stop sharing** at any point to cancel the capture.
2. A floating panel appears with two capture options:

   - **Visible tab area**: Captures the entire tab.
   - **Selected area**: Captures a specific area of the tab.
3. Extend the selection if needed, then click **Capture**.

 NOTE

Use the **Drag and drop** () icon to move the floating panel wherever you prefer.

### If you selected a window

The selected window is captured automatically. There is no floating panel and no area selection.

### Edit and insert the capture

After capturing, you are redirected to the Knowledge base portal. The captured image appears in a panel with image editing tools such as Resize, Crop, Flip, Rotate, Draw, Shape, Icon, Text, and Filter.

1. Make your adjustments using the editing tools. To add text in more than one language, see [Add text in other languages](/en/docs/screen-capturing-from-the-editor#add-text-in-other-languages).
2. Click **Insert** to add the image to the article, or **Cancel** to discard the capture.

## Add text in other languages

When you add text to a captured image using the **Text** tool, you can enter the text in more than one language. Readers see the text that matches the language they select on the knowledge base site.

To add text in other languages:

1. In the image editing panel, select **Text** and add your text.
2. Select the language you want to add the text for.
3. Enter the text for that language.
4. Repeat for each language you need.
5. Click **Insert** to add the image to the article.

## Considerations

| Item | Detail |
| --- | --- |
| Maximum image size | 150 MB |
| File format | Captured images are saved as PNG |
| File naming | Automatic, using the prefix `image_` followed by the capture timestamp, for example `image_20250104153021.png` |
| Storage | All captures are uploaded to Document360 Drive, in the default **Images** folder, with any captions and alt text you added |
| Capture scope | Browser tabs and application windows only. Full desktop capture is not supported |
| Editor support | Advanced WYSIWYG editor and unified Editor |

## FAQ

<Expandable title="Can I edit a captured image before inserting it into an article?">
  Yes. The captured image opens in an editing panel with tools to resize, crop, flip, rotate, draw, add shapes, text, and filters. Make your adjustments, then click **Insert**.
</Expandable>

<Expandable title="What happens if I navigate away while capturing a screen?">
  A panel appears in the Knowledge base portal indicating that the capture is still in progress.
</Expandable>

<Expandable title="What happens if a captured image exceeds the maximum size limit?">
  An error message appears. To resolve this, reduce the screen area or lower the image resolution before capturing again.
</Expandable>

<Expandable title="Can I capture screens from any application or only from the browser?">
  You can capture browser tabs and application windows. Full desktop screen capture is not supported.
</Expandable>

<Expandable title="Can I add text in multiple languages to a captured image?">
  Yes. When you add text using the **Text** tool, select the language and enter the text for each language you need.
</Expandable>
