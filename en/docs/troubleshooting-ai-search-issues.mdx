This section provides a solution to an issue you may encounter when using Eddy AI to display search results in Document360.

### Eddy AI displays incorrect dates in search results

**Error**: Eddy AI may display inaccurate dates when showing search results.

**Steps to resolve**:

To troubleshoot inaccurate date calculations in Eddy AI search results, follow these steps:

1. Perform a keyword search. Check if Eddy AI returns the expected results when using non-date-based keywords.
2. If results are correct for general searches but differ for date-based keywords, note that Eddy AI is optimized for text-based responses and may not process date-specific queries as expected.
3. If search results remain irrelevant, contact **support@document360.com** with the following details:

   - Reader access to your projects.
   - A recording of the search queries you used and the results that did not populate as expected.

> **NOTE**
> 
> - Eddy AI is a language model, not a computational engine. It generates responses based on text patterns rather than analytical reasoning or numerical computations.
> - It cannot calculate or interpret time-based scenarios unless explicitly defined in the input.

### Empty cells in tables are auto-filled in Eddy AI responses

When a response is structured using a table and includes empty cells, Eddy AI attempts to dynamically populate those cells based on the context of the user’s query. If no relevant information is found, it fills the cell with the placeholder text <strong>"Information not available."</strong>

How Eddy AI handles empty cells:

- It checks the context of the user’s question.
- It tries to insert relevant content into any empty cells.
- If nothing appropriate is found, the cell is filled with <strong>"Information not available."</strong>

To maintain accuracy and clarity:

- Avoid leaving table cells empty when drafting or editing content.
- Ensure all cells contain meaningful information to prevent unintended or generic fillers in the final response.

### Unsupported format error when adding a sitemap

<strong>Error message:</strong> `Unsupported format`

This error occurs when the sitemap contains nested sitemaps using the `<sitemapindex>` tag, exceeds 1 MB in file size, or is not in a supported format.

<strong>To resolve:</strong>

- Use only a direct sitemap URL — nested sitemaps with `<sitemapindex>` are not supported.
- Ensure the sitemap file is under **1 MB**.
- Verify the sitemap is in **XML format**.

### HTML5 format error when adding a webpage

<strong>Error message:</strong> `Only HTML5 documents with <article> or <main> tags`

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793777877583-d4u3ugovqcq-9_Screenshot-Troubleshooting_Only_HTML5_documents_with_article_or_main_tags.png?fm=auto&auto=compress%2Cformat" alt="Manage sources page showing the HTML5 format error when adding a webpage that lacks the required article or main tags." />

This error occurs when the webpage is not in HTML5 format or does not contain the required `<article>` or `<main>` tags.

<strong>To resolve:</strong>

- **Verify the HTML5 doctype** — the page should declare `<!DOCTYPE html>` at the top.
- **Check for required tags** — view the page source (`Ctrl+U` / `Cmd+U`) and confirm the page contains `<article>` or `<main>` tags.
- **Update the page** — if either requirement is not met, update the webpage to conform before adding it as a source.

### Unsupported language error when adding a webpage

<strong>Error message:</strong> `Error due to unsupported language`

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793777878022-rgi5yw3b1i-image-1741777460375.png?fm=auto&auto=compress%2Cformat" alt="Manage sources page showing the unsupported language error when adding a webpage whose language is not configured in the knowledge base." />

This error occurs when Eddy AI does not support the language of the webpage, or when the language is supported but has not been added to your project's localization settings.

<strong>To resolve:</strong>

1. Check whether the webpage's language is supported by Eddy AI — see [Multilingual support for Eddy AI Search Suite](https://docs.document360.com/help/docs/ai-search-suite#multilingual-support-for-eddy-ai-search-suite).
2. If the language is supported, ensure it is added to your project. For example, if you are adding `https://abc.document360.com/fr/document`:

   1. In the Knowledge Base portal, select **Settings** in the left navigation bar.
   2. In the left navigation pane, go to **Knowledge base portal** > **Workspace & localization**.
   3. Confirm that French (`fr`) is available in the selected workspace.
3. If the issue persists, contact Document360 support.

### Eddy AI synthesizes incorrect or misleading answers from multiple articles

<strong>Error:</strong> `When multiple articles share a common keyword (for example, "GDPR"), Eddy AI may retrieve loosely related content from several articles and synthesize a response that is inaccurate or misleading for the actual question asked.`

<strong>Steps to resolve:</strong>

1. Open the Eddy AI **Feedback manager** in the Knowledge base portal and locate the query that produced the incorrect response.
2. Review the citations in the response to identify which articles Eddy retrieved and whether each one is genuinely relevant to the question.
3. If an article mentions the keyword only incidentally, revise or contextualize that mention so the article does not surface for unrelated queries.
4. If no single article directly answers the question, create one. The more precisely an article covers a specific question, the more reliably Eddy AI retrieves and cites it.
5. To narrow what Eddy AI searches, use the **Content access** control on the **Manage sources** page (**Settings** () > **AI settings**) to restrict retrieval to specific workspaces, languages, and categories.
6. After making content changes, wait approximately 15 minutes for the index to update, then ask the same question again on the knowledge base site to verify the response.

 NOTE

Eddy AI is constrained to your knowledge base content and responds with "I do not know" when it cannot find a reliable source. If incorrect synthesis persists after content changes, contact [support@document360.com](mailto:support@document360.com) with the query, the response received, and the cited article URLs.

### Citation or reference missing for part of an Eddy AI response

<strong>Error:</strong> A response generated by Eddy AI, whether through AI assistive search, the Eddy AI chatbot, or federated search, includes some content that does not have a numbered citation attached to it, even though a citation is expected.

This is expected behavior. Eddy AI generates each response by drawing on your knowledge base content, external sources, and previous conversation context. A citation is added only when Eddy AI can confidently map a specific part of the response back to a single published source. If Eddy AI used a piece of content but cannot reliably confirm which published article or source it came from, it intentionally omits the citation for that part of the response rather than showing a broken or incorrect link. This ensures that any citation a reader sees can be trusted to open the correct source.

To troubleshoot missing citations, follow these steps:

1. Confirm the source article or external source is published and active. Eddy AI does not index draft articles, and a deactivated external source will not be cited.
2. Confirm the source is included in Eddy AI's content access settings. Go to Settings, then AI settings, then Manage sources, and check that the relevant workspace, language, or category is not excluded under Content access.
3. If the source is a recently published article, allow approximately 15 minutes for Eddy AI's index to update before checking again.
4. If the source is a recently added or updated external source, such as a webpage or sitemap, allow up to 24 hours for the automatic sync, or trigger a manual sync from the Manage sources page. Manual sync is available up to four times per day.
5. If the source meets all of the above and the citation is still missing, the response likely draws on the source only loosely or indirectly, and Eddy AI could not confidently confirm the match. Review the query and response in the Eddy AI Feedback manager, and consider revising the source content to more directly and unambiguously address the question, so Eddy AI can cite it reliably.

NOTE

A response missing a citation for part of its text does not mean the content is inaccurate. It means Eddy AI could not confidently confirm a single source for that part.
