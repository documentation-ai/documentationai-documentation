The **Tasks page** is the dedicated view for managing all your assigned documentation tasks in Document360. It lists every task assigned to you across all timeframes, covering three task types: Workflow, Feedback, and Review reminders. Unlike the Tasks card on the [Overview page](/en/docs/overview-page), which shows only the current week, the Tasks page gives you the complete picture with full filtering, search, and bulk action capabilities.

 NOTE

If you previously used the Workflow assignment page (sometimes referred to as the Workflows page), that page has been removed. Its functionality is now part of the Tasks card on the [Overview page](/en/docs/overview-page).

---

## When to use the Tasks page

Use the Tasks page when you need to:

- Review all tasks assigned to you regardless of due date, not just this week's tasks.
- Apply advanced filters to find tasks by assignee, label, status, or a custom date range.
- Perform bulk actions such as updating the workflow status of multiple articles at once.
- Track tasks as an admin, including tasks assigned to other users or user groups.

For a quick daily check on this week's priority tasks, the Tasks card on the [Overview page](/en/docs/overview-page) is a faster starting point.

## Understanding task types

The Tasks page displays three task types. Each type reflects a different source of work assigned to you.

**Workflow tasks**

Articles in which you are assigned any workflow status.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793777362238-l1mbiknrjgs-image-1767587177626.png?fm=auto&auto=compress%2Cformat" alt="Tasks page filtered to show workflow tasks with status and due date columns" />

**Feedback tasks**

Reader feedback and No search result feedback for articles, and Answered or Unanswered query feedback for Eddy AI, all assigned to you from the Feedback manager.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793777364159-a482q8hjaad-image-1767587194497.png?fm=auto&auto=compress%2Cformat" alt="Tasks page filtered to show feedback tasks assigned from the Feedback manager" />

**Review reminders**

Articles marked as Needs review for which you are a contributor.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793777365785-ybu6hmwzr7j-image-1767587209750.png?fm=auto&auto=compress%2Cformat" alt="Tasks page filtered to show review reminder tasks with overdue indicators" />

 NOTE

Tasks without a due date are listed under Today by default. A hyphen is shown in the due date column and a tooltip indicates that no due date has been set.

Each task displays key details including the article title, task type, current status, due date, assigned users, labels, and last update information.

## Task table

The Tasks page displays the following columns by default:

| Column | What it shows |
| --- | --- |
| **Title** | The article associated with the task. |
| **Type** | The task type: workflow, feedback, or review reminder. |
| **Status** | The current status of the task. |
| **Due** | The date by which the task is expected to be completed. |
| **Labels** | Labels associated with the article linked to the task. |
| **Assigned by** | The user who assigned the task. |
| **Assigned to** | The user(s) and user group(s) responsible for the task. |
| **Last updated at** | The date, time, and user of the most recent update. For workflows, this reflects the last article update. For feedback, it shows the last update to that feedback item. For review reminders, it indicates the last article update. |

When you view the **Snoozed** section, two additional columns appear:

| Column | What it shows |
| --- | --- |
| **Snoozed at** | The date and time when the task was snoozed. |
| **Snoozed until** | The date and time when the task becomes active again. |

## Managing your tasks

You can act on tasks directly from the list using hover actions, the More options menu, or checkbox selection for bulk actions.

### Hover actions

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793777366222-nqran8q109m-image-1767587265108.png?fm=auto&auto=compress%2Cformat" alt="Task row with hover actions showing the Snooze icon and a task-specific action icon" />

When you hover over a task, two actions appear:

- **Snooze** (available for all task types): Postpone the task to <strong>Tomorrow (9 AM)</strong>, <strong>Next week (same weekday next week, 9 AM)</strong>, or a **custom date and time**.
- One task-specific action:

  - Workflow tasks: **Update workflow status**
  - Feedback tasks: **Manage feedback**
  - Review reminder tasks: **Mark as reviewed**

### More options menu

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793777368282-qxz6tkbbggs-more-options-home-page.png?fm=auto&auto=compress%2Cformat" alt="More options menu on a task row showing Mark as done, Publish, Publish later, and Add labels" />

Click the More options icon to access additional actions per task type:

- <strong>Workflow tasks:</strong> Mark as done, Publish, [Publish later](/docs/schedule-publishing), Add labels
- <strong>Review reminders:</strong> Publish, Publish later, Add labels

### Selection actions

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793777370050-7mopcbu890u-image-1772012519042.png?fm=auto&auto=compress%2Cformat" alt="Multiple tasks selected with the bulk action toolbar showing Publish, Update workflow status, and Snooze options" />

Select the checkbox next to an article name to access:

- <strong>Workflow tasks:</strong> Publish, Publish later, Update workflow status, Snooze, Add labels, Mark as done
- <strong>Feedback tasks:</strong> Snooze, Manage feedback
- <strong>Review reminders:</strong> Publish, Publish later, Snooze, Add labels, Mark as reviewed

 NOTE

- If an article is marked as **Needs review** and is already **Published**, the task appears in the list but the **Publish** and **Publish later** actions are not shown.
- When you select multiple tasks, only the actions common to all selected task types appear in the toolbar.

### Manage tasks through an AI assistant

If your project uses [Document360 MCP](/en/docs/mcp), you can also view and act on your tasks from a connected AI assistant. The AI assistant can list the tasks assigned to you, snooze or unsnooze your tasks, mark a workflow task as done, and update the status of feedback assigned to you. Through MCP, all users, including Admins, can view and act on their own tasks only. For more information, see [Supported MCP tools](/en/docs/supported-mcp-tools).

## Filtering and searching tasks

You can narrow the task list using task type tabs, column filters, the assignee filter, and the search bar.

### Filter by task type

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793777371805-nc5vbou2d2-image-1767587826336.png?fm=auto&auto=compress%2Cformat" alt="Task type filter tabs at the top of the Tasks page showing Workflow, Feedback, and Review reminder options" />

Click one or more tabs at the top of the list to filter by **Workflow**, **Feedback**, or **Review reminder**. You can select multiple task types at the same time.

### Filter by column

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793777372391-g515abtea4k-image-1767587845231.png?fm=auto&auto=compress%2Cformat" alt="Column filter panel on the Tasks page showing Status, Due date, Labels, Assigned by, Last updated at, and Last updated by dropdowns" />

Click the **Filter** icon to open the filter panel and apply the following filters:

**Status**

Filter tasks by their current status. The dropdown groups statuses by task type:

- Workflow tasks: statuses defined in the Workflow Designer (e.g., Draft, In review)
- [Feedback tasks](/en/docs/feedback-manager-overview): Open, Planned, In Progress
- [Review reminder tasks](/en/docs/review-reminders): Needs review

<strong>Due date (timeline)</strong>

Filter by when tasks are due:

- <strong>This week:</strong> Tasks due during the current calendar week (Sunday to Saturday)
- <strong>Today:</strong> Tasks due today, including tasks with no due date
- <strong>Overdue:</strong> Tasks with a past due date
- <strong>Custom date:</strong> Choose a specific due date

 NOTE

Tasks assigned to you without a due date automatically appear under Today. They remain on today's list and are not marked as overdue.

**Labels**

Use the **Labels** dropdown to filter tasks linked to articles with specific labels. You can select one or more labels.

**Assigned by**

Use the **Assigned by** dropdown to view tasks created by a specific user. This is useful when tracking tasks from a particular team member or source.

**Last updated at**

Use the **Last updated at** dropdown to filter tasks based on recent activity, helping you spot tasks updated recently or tasks that have not been touched for a while.

**Last updated by**

Use the **Last updated by** dropdown to filter tasks based on who made the most recent update.

### Filter by assignee

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793777374366-e5xibjhy4x-image-1767587867027.png?fm=auto&auto=compress%2Cformat" alt="Assignee filter dropdown on the Tasks page showing Assigned to me, Unassigned, Snoozed task, All users, Specific users, and Groups options" />

Use the **Assigned to me** dropdown to filter tasks by who they are assigned to:

- <strong>Assigned to me:</strong> Displays only tasks assigned to you.
- <strong>Unassigned:</strong> Displays tasks with no assignee.
- <strong>Snoozed task:</strong> Displays tasks you have snoozed.
- <strong>All users:</strong> Displays tasks assigned to all users. <em>(Admins only)</em>
- <strong>Specific users:</strong> Select one or more users from the list. <em>(Admins only)</em>
- <strong>Groups:</strong> Switch to the Groups tab to filter by team groups. <em>(Admins only)</em>

 NOTE

**Admins** can view and manage tasks assigned to any user or group and can filter unassigned tasks. However, they cannot snooze tasks assigned to others or view tasks snoozed by others. **Regular users** can only view and manage tasks assigned to themselves.

### Search bar

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793777375930-1caj0jz5tcf-image-1767587883730.png?fm=auto&auto=compress%2Cformat" alt="Search bar on the Tasks page with a partial article name typed in the input field" />

Use the search bar to find tasks by article name. The search runs in real time and matches both partial and complete titles.

## Best practices

- <strong>Resolve overdue tasks before starting new work.</strong> Use the **Overdue** timeline filter at the start of each sprint to clear stale assignments before they block a release.
- **Use the Assignee filter as an admin** to check workload distribution across the team before assigning new tasks. Filtering by **All users** shows you who is under- or over-assigned.
- **Snooze tasks you cannot address immediately** rather than leaving them in the active list. Choose a realistic future date so the task resurfaces when you are ready to act on it.
- **Combine task type and status filters** to focus your view. For example, filter by Workflow + In review to see only articles currently waiting for your review sign-off.
- **Use bulk Update workflow status** when moving a batch of articles to the next stage together, such as at the end of a content sprint.
- **Search by article name** when you receive a notification about a specific article and want to locate its task quickly without scrolling.

## FAQ

<Expandable title="What is the difference between the Tasks page and the Tasks card on the Overview page?">
  The Tasks page lists all tasks assigned to you across all timeframes and provides full filtering, search, and bulk action capabilities. The Tasks card on the Overview page shows only tasks due during the current calendar week (Today, This week, Overdue, and Snoozed). Use the Tasks card for a quick daily check-in and the Tasks page for deeper task management.
</Expandable>

<Expandable title="Why does a task without a due date appear under Today?">
  Tasks without a due date are grouped under Today by default to ensure they remain visible and actionable. A hyphen is displayed in the Due column and a tooltip confirms that no due date has been set. These tasks will not be marked as overdue even if they remain on the Today list for multiple days.
</Expandable>

<Expandable title="Can I see tasks assigned to other team members?">
  Yes, but only if you are an Admin. Admins can use the Assigned to me dropdown and select All users, Specific users, or Groups to view tasks across the team. Regular users can only see their own assigned tasks. Admins cannot snooze tasks assigned to others or view tasks that others have snoozed.
</Expandable>

<Expandable title="Why are the Publish and Publish later actions missing for some tasks?">
  If an article is already in Published status and is also marked as Needs review, the Publish and Publish later actions are hidden for that task. The article is already live, so no re-publishing action is needed. You can still perform other actions such as Mark as reviewed.
</Expandable>
