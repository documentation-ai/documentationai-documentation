title: Add a folder

---

The **Drive** in Document360 lets you organise your knowledge base assets, images, files, and attachments, into folders and subfolders. Creating a well-structured folder hierarchy makes it easier to locate files, maintain consistency across your knowledge base, and avoid broken image or file links in articles.

---

## Before you begin

- To add subfolders, you need at least two root-level folders already created in Drive, or one root-level folder that is expanded.
- Deleting a root-level folder moves it, along with its subfolders and files, to the Recycle bin, where they are deleted after 30 days. This can break image and file links in any article referencing those files.

---

## Add a new folder

There are two ways to do this:

1. [Using the 'New folder' option](/en/docs/add-a-folder#using-the-new-folder-option-to-add-a-folder)
2. [Using the '+' option](https://docs.document360.com/help/docs/add-a-folder#using-the-option-to-add-a-folder)

---

### Using the 'New folder' option to add a folder

1. Navigate to **Drive** () in the left navigation bar of the knowledge base portal.<br /> Existing folders and subfolders are displayed in a tree-view style on the left navigation pane.
2. Click the **New folder** option at the top left.<br /> A **New folder** dialog appears.
3. Enter the **Folder name**.
4. The folder location is set to **Root level** by default. Use the **Folder location** dropdown to select a different location if needed.
5. Click **Create**.

<Image src="https://cdn.document360.io/860f9f88-412e-4570-8222-d5bf2f4b7dd1/Images/Documentation/new%20folder%283%29.png" alt="Creating a new folder named 'Artifacts related to release notes' using the New folder dialog in Document360." />

---

### Using the '+' option to add a folder

1. Navigate to **Drive** () in the left navigation bar of the knowledge base portal.<br /> Existing folders and subfolders are displayed in a tree-view style on the left navigation pane.
2. In the left navigation pane, hover over the space between folders until the <strong>Flywheel (+)</strong> icon appears.
3. Click the <strong>+</strong> icon.<br /> A **New folder** popup appears.
4. Enter the desired folder name.
5. The default location is **Root level**. To add a root-level folder from anywhere in Drive, use the folder location dropdown and click **Reset**.
6. Click **Create**.

## Add a subfolder

There are two ways to do this:

1. [Using the 'More' option](https://docs.document360.com/help/docs/add-a-folder#using-the-more-option-to-add-a-subfolder)
2. [Using the '+' option](https://docs.document360.com/help/docs/add-a-folder#using-the-option-to-add-a-subfolder)

---

### Using the 'More' option to add a subfolder

1. Navigate to **Drive** () in the left navigation bar of the knowledge base portal.
2. Click the **More** () icon next to the folder where you want to add a subfolder, then select **Add folder**.<br /> The **New folder** dialog appears.
3. Enter the **Folder name**.
4. The folder location defaults to the folder you selected. Use the location dropdown to change it if needed.
5. Click **Create**.

<Image src="https://cdn.document360.io/860f9f88-412e-4570-8222-d5bf2f4b7dd1/Images/Documentation/add%20folder.png" alt="Menu showing the Add folder option in the Document360 Drive interface." />

---

### Using the '+' option to add a subfolder

1. Navigate to **Drive** () in the left navigation bar of the knowledge base portal.
2. In the left navigation pane, hover over the space between folders until the <strong>+</strong> icon appears.
3. Click the <strong>+</strong> icon.<br /> A **New folder** dialog appears.
4. Enter the desired folder name. The default location is the folder where you clicked <strong>+</strong>. Use the location dropdown to add the subfolder anywhere in Drive.
5. Click **Create**.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793777437759-fxwuhdy2t6h-subfolder.png?fm=auto&auto=compress%2Cformat" alt="Creating a new subfolder named 'Doc360' in the Document360 Drive interface." />

 NOTE

Ensure the root-level folder is expanded (the arrow on its left side points downward) before adding a subfolder. If the folder is collapsed, the new folder will be created at the same level instead of nested inside it.

 CAUTION

Deleting a root-level folder moves it, along with all its subfolders and files, to the Recycle bin, where they are deleted after 30 days. This can cause broken images and file links in any articles referencing those files.

## Best practices

- <strong>Mirror your knowledge base structure.</strong> Keep Drive folders aligned with your knowledge base categories and subcategories so assets are intuitive to find for anyone on your team.
- <strong>Name folders consistently.</strong> Use a clear, descriptive naming convention (for example, `release-notes-assets` or `onboarding-images`) to avoid ambiguity.
- <strong>Review before deleting.</strong> Before removing a root-level folder, check whether any articles link to files inside it to prevent broken links.

## FAQ

<Expandable title="Can I add a subfolder without creating a root-level folder first?">
  No. You need at least one root-level folder in Drive before you can add a subfolder. Create a root-level folder first using either the **New folder** option or the <strong>+</strong> icon, then add subfolders inside it.
</Expandable>

<Expandable title="Why is the 'Add folder' option greyed out for some folders?">
  **Images** is the only System folder in Drive. You can add subfolders and files inside it, change its color, and set it as the default folder, but you can't rename or remove it. Its system subfolders (**Settings**, **Documentation**, **Home page builder**, and **Glossary**) are locked, so folder actions such as **Add folder** aren't available for them.
</Expandable>

<Expandable title="What happens to articles if I delete a folder?">
  Deleting a root-level folder moves it, along with all its subfolders and files, to the Recycle bin, where they are deleted after 30 days. Any articles that reference those files will have broken images or file links. Always review article dependencies before deleting a folder.
</Expandable>

<Expandable title="Can I move a subfolder to a different root-level folder?">
  You can select a different location using the **Folder location** dropdown when creating a folder. To move an existing subfolder, use the folder's **More** () menu options available in Drive.
</Expandable>
