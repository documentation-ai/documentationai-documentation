### Powered by MDX

Save time and focus on text documents. Simply write docs and blog posts with MDX, and Docusaurus builds them into static HTML files ready to be served. You can even embed React components in your Markdown thanks to MDX.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793700785223-kxva2i7ul99-undraw_react.svg?rasterize-bypass=true" alt="Built Using React" width={1108} height={731} />

### Built Using React

Extend and customize your project's layout by writing React components. Leverage the pluggable architecture, and design your own site while reusing the same data created by Docusaurus plugins.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793700785819-9uogayez5fl-undraw_around_the_world.svg?rasterize-bypass=true" alt="Ready for Translations" width={1137} height={776} />

### Ready for Translations

Localization comes out-of-the-box. Use git, Crowdin, or any other translation manager to translate your docs and deploy them individually.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793700856655-cok7b6pu1d-undraw_version_control.svg?rasterize-bypass=true" alt="Document Versioning" width={1038} height={693} />

### Document Versioning

Support users on all versions of your project. Document versioning helps you keep documentation in sync with project releases.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793700856730-2b472ok6vrf-undraw_algolia.svg?rasterize-bypass=true" alt="Content Search" width={1137} height={736} />

### Content Search

Make it easy for your community to find what they need in your documentation. We proudly support Algolia documentation search.
