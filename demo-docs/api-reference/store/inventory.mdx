## List inventory

> Returns current stock levels for all pets in the store.

**GET** `/inventory`

**Parameters**

<ParamField header="Authorization" param-type="string" required={true}>
  Pass your API key as a Bearer token in the `Authorization` header.
</ParamField>

**Responses**

`200` An array of inventory entries.

<ResponseField name="petId" field-type="integer" required={true}>
  The ID of the animal this entry tracks.
</ResponseField>

<ResponseField name="quantity" field-type="integer" required={true}>
  Current stock count.
</ResponseField>

<ResponseField name="status" field-type="string" required={true} enum="available,pending,sold" />

`401` Missing or invalid API key.

<ResponseField name="code" field-type="string" required={true}>
  A machine-readable error code.
</ResponseField>

<ResponseField name="message" field-type="string" required={true}>
  A human-readable description of the error.
</ResponseField>

<ResponseField name="status" field-type="integer" required={true}>
  The HTTP status code.
</ResponseField>

## Update stock level

> Updates the stock quantity for a specific pet. Use this to record new arrivals, returns, or manual adjustments.
> 
> <Callout kind="alert">
>   This endpoint is **experimental** — the request shape may change before it reaches stable.
> </Callout>

**PATCH** `/inventory/{petId}`

**Parameters**

<ParamField header="Authorization" param-type="string" required={true}>
  Pass your API key as a Bearer token in the `Authorization` header.
</ParamField>

<ParamField path="petId" param-type="integer" required={true}>
  The ID of the pet to update stock for.
</ParamField>

**Request body**

<ParamField body="quantity" param-type="integer" required={true}>
  The new stock count.
</ParamField>

**Responses**

`200` Updated inventory entry.

<ResponseField name="petId" field-type="integer" required={true}>

</ResponseField>

<ResponseField name="quantity" field-type="integer" required={true}>
