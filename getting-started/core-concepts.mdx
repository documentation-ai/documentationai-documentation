# Important Concepts

Welcome! If you're new to Documentation.AI, these concepts will help you get oriented quickly. Think of this as your guided tour of the platform's key ideas: how it stays AI-native, the two ways you can work, how components make your docs richer, and how API documentation fits in. Once you understand these building blocks, everything else will feel natural.

<Callout kind="info" collapsed="false">
  If you want a quick end-to-end setup, see the [Quickstart](/getting-started/quickstart).
</Callout>

## Two ways to work

Documentation.AI supports two fully synced workflows, so each contributor can use the environment that fits their role and habits.

Components make pages easier to scan and keep patterns consistent across your documentation. They also add structure that helps AI systems interpret the meaning of each section more accurately.

    Combine components to create predictable, readable patterns across your docs.

  <Card title="API Components" href="/components/api-components" icon="code" cta="View API blocks" horizontal="false" target="_self">
