## Recent Changes

<Callout kind="info">

Track the evolution of Documentation.AI with release notes that highlight what changed, what improved, and what your team should update.

<Update label="2025-03-12" description="v2.0.0" tags={["feature","improvement","bugfix"]}>
  ## New Features

  - Added workspace-level content governance controls so editors can enforce review requirements before pages are published.
  - Introduced reusable API example blocks that keep request and response snippets consistent across reference pages.
  - Added AI-assisted migration suggestions to help teams update MDX pages when component syntax changes.

  ## Improvements

  - Improved page build performance for large documentation sets with faster incremental compilation.
  - Refined changelog, reference, and help center layouts for better scanning on desktop and mobile.
  - Expanded search indexing to surface headings, callouts, and field-level reference content more reliably.

  ## Bug Fixes

  - Fixed inconsistent rendering when nested interactive components appeared inside expandable sections.
  - Resolved an issue that could duplicate sidebar items after navigation updates.
  - Corrected code block focus and highlight behavior in long multi-example pages.
</Update>

<Update label="2025-01-24" description="v1.9.0" tags={["feature","improvement","bugfix"]}>
  ## New Features

  - Added navigation-aware collection components for building landing pages from documentation structure.
  - Introduced richer card layouts for section overviews and related-resource pages.
  - Added support for structured changelog entries with tags for features, improvements, and fixes.

  ## Improvements

  - Improved MDX validation feedback so authors can identify parsing issues before deployment.
  - Updated default component styling for clearer spacing in task-oriented guides and API references.
  - Reduced search latency for medium-sized sites and improved result relevance for exact page titles.

  ## Bug Fixes

  - Fixed broken heading anchors in pages that contained repeated subsection titles.
  - Resolved an issue where internal links could lose their relative path during content imports.
  - Fixed inconsistent tab selection persistence after page refreshes.
</Update>

## How to Update

<Steps>
  <Step title="Check your current version" icon="package">

  Confirm which Documentation.AI version your project uses before you upgrade.

  ```bash
  npx documentation-ai --version
  ```

  Your terminal prints a version such as `1.9.0` or `2.0.0`.

  </Step>

  <Step title="Upgrade the platform package" icon="upload">

  Install the latest release with your preferred package manager.

  <CodeGroup tabs="npm,yarn,pnpm">
  ```bash
  npm install documentation-ai@latest
  ```

  ```bash
  yarn add documentation-ai@latest
  ```

  ```bash
  pnpm add documentation-ai@latest
  ```
  </CodeGroup>

  After the install completes, your lockfile should show the updated package version.

  </Step>

  <Step title="Rebuild and verify" icon="check-circle">

  Restart your docs environment and confirm the new release loads without MDX or navigation errors.

  ```bash
  npm run docs:dev
  ```

  Success looks like a clean local build and the updated version reported by the CLI.

  </Step>
</Steps>
