## Export your published docs as a PDF

PDF export creates a single PDF from all published pages in one documentation site. Use it when you need an offline copy, want to share a fixed snapshot of your docs, or need a file for review and archival.

The export runs in the background after you request it from the dashboard. You can leave the page while it processes and come back later to check the status or download the file.

<Callout kind="info">

PDF export is available on **Standard**, **Professional**, and **Enterprise** plans.


</Callout>

## Request a PDF export

Request the export from your documentation site's dashboard. The system then starts building one PDF that includes every published page in that site.

<Steps>

  <Step title="Open your documentation site" icon="book-open">

  In the dashboard, open the documentation site you want to export. Make sure the content you want included is already published.


  </Step>
  <Step title="Start a PDF export" icon="download">

  Find the PDF export option and submit a new export request. The export starts in the background after you confirm the request.

  If your site already has an existing export, the new request replaces it. Only one export can exist per documentation site at a time.


  </Step>
  <Step title="Wait for processing to finish" icon="settings">

  After you submit the request, the export moves through its processing states in the dashboard. You do not need to keep the page open while it runs.


  </Step>
</Steps>

<Callout kind="tip">

When the PDF is ready, you receive an email notification so you do not need to keep checking the dashboard.


</Callout>

## Export status and progress

The dashboard shows the current state of your export so you can tell whether it is waiting, running, finished, or needs attention.

### Pending

**Pending** means the export request was accepted and is waiting to start. You do not need to do anything during this stage.

### Processing

**Processing** means the PDF is actively being generated. Large documentation sites can take longer, especially when they contain many published pages.

### Completed

**Completed** means the PDF is ready to download from the dashboard. At this point, the email notification is also sent.

### Failed

**Failed** means the export did not complete successfully. If this happens, request a new export from the dashboard.

### Cancelled

**Cancelled** means someone stopped the export before it finished. A cancelled export does not produce a downloadable PDF.

## Download your PDF

Once the export shows as completed, download the file directly from the dashboard.

<Steps>

  <Step title="Open the completed export" icon="check-circle">

  Return to your documentation site in the dashboard and find the completed PDF export.


  </Step>
  <Step title="Download the file" icon="download">

  Select the download link for the completed export. The file downloads as a single PDF containing all published pages from that site.


  </Step>
  <Step title="Save a local copy" icon="folder">

  Store the file somewhere your team can access if you need it for review, sharing, or records. The dashboard download remains available for a limited time.


  </Step>
</Steps>

<Callout kind="alert">

Completed PDF exports stay available for **7 days**. Download the file before the link expires.


</Callout>

## Cancel an export

Cancel an export if you requested it by mistake or need to stop the current run before starting another one.

<Steps>

  <Step title="Find the in-progress export" icon="settings">

  Open your documentation site in the dashboard and locate the export with a status of **pending** or **processing**.


  </Step>
  <Step title="Cancel the export" icon="x-circle">

  Use the cancel option for that export. The status changes to **cancelled**, and the export stops running.


  </Step>
</Steps>

## Limitations

<Callout kind="info">

PDF exports include up to **8,000 published pages** per export.


</Callout>

<Callout kind="info">

Only **one PDF export per documentation site** is available at a time. Requesting a new export replaces any existing one.


</Callout>

<Callout kind="alert">

Download links remain available for **7 days after completion**. After that window ends, request a new export if you still need the file.


</Callout>
