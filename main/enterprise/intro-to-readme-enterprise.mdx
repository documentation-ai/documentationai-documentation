ReadMe Enterprise brings multiple projects together under a single organization, on top of everything included in standard plans. It adds [Group-level design](/main/enterprise/enterprise-design-settings) and [reusable content](https://docs.readme.com/main/enterprise/reusable-content-enterprise) for consistency across projects, [granular user roles](/main/enterprise/user-roles) and [SSO](/main/enterprise/setting-up-sso) for access control, and [audit logs](/main/enterprise/audit-logs) for tracking changes across your Group.

## Enterprise Features

These features are exclusive to Enterprise plans — use the guides below to configure your Group-level settings, authentication, and workflow tooling.
