### Owner

Owners can delete the project and remove Admins. If your project Owner can no longer manage your project, reach out to [support@readme.io](mailto:support@readme.io) or your assigned customer success manager for assistance.

### Admin

Admins have access to settings and content, and can invite other Admins or Editors, though they cannot remove other Admins.

### Editor

Editors can edit any page, Reusable Content, Components, Glossary, Versions, and the Landing Page. They cannot edit settings such as Custom CSS or Site Navigation, and cannot invite Teammates. An Editor edits a version directly only when the project's merge access level is set to **Admins & Editors** on the group's **Projects** page. Otherwise, an Editor makes edits within a branch of a version.

### Viewer

Viewers can only view docs and branches, along with [changes, diffs, and linter results](/main/docs/reviews#review-changes).

## Project and Group Roles

Give Teammates custom access to specific projects — for example, you can make someone an Admin on one project and an Editor or Viewer on another.

Group Admins, Group Editors, and Group Viewers automatically have access to every project in your Enterprise Group. Of those, only Group Admins and Group Editors can access the Enterprise Dashboard; Group Viewers cannot.

By contrast, a project-level role (Admin, Editor, or Viewer) only grants access to the specific project it's assigned.
