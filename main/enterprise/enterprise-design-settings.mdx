Group design settings exist at the Enterprise Group level and apply to all projects in the group. These are additional to the design settings offered within each project.

---

## Footer Options

Check the box to remove the ReadMe logo from the site footer across all projects in your Enterprise Group.

## Theme Editor

The **Theme Editor** in your Enterprise Group lets you do the following:

- Set or update white and dark logos.
- Set or update the favicon.
- Select the sub-header layout.
- Set the primary color theme for homepage components, such as Search.

## Custom Styling

Set custom stylesheets, JavaScript, and include tags at the Group level to apply them across all child projects. For details on how Group styles interact with project styles, see [Custom HTML/CSS/JS](/main/enterprise/custom-htmlcssjs).
