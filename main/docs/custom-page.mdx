Use Custom Pages when you want to keep your ReadMe project's top navigation but customize everything below the search bar.

# What's different?

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793774260627-n79yrfkecar-34ffc014720bff814cca58867685fefeba1ce50f1a263e901d2739a6b8605139-custom_page_vs_regular.png?fm=auto&auto=compress%2Cformat" alt="Left: Custom Page, Right: Docs page" caption="Left: Custom Page  | Right: Guides Page" />

Custom Pages change a few things compared to standard Documentation pages:

1. No left sidebar navigation
2. No table of contents, even if headers are used
3. A different URL path (`/page` instead of `/docs`)
4. No page voting
5. No "Updated x days ago"

<Callout kind="alert">


  Custom Pages are not affected by versioning and are shared. If you delete a Custom Page it will be removed from everywhere.
</Callout>

# What's the same?

You can add a Custom Page to your subnavigation in **Appearance > Navigation**. It will appear as a new item using the same header name or a custom title.

## Modes

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793774260927-rhpgzk51v5-2f7b74f1ba51fdea468e6f1063bd2c4efe2e8dc59950fba57dfb936798461910-ed935b55d28724c36005d4c14315b331.png?fm=auto&auto=compress%2Cformat" alt="Markdown or HTML Mode" />

Custom Pages support two modes:

1. <strong>Markdown:</strong> The standard mode used in the Documentation section
2. <strong>HTML:</strong> HTML is [sanitized](https://en.wikipedia.org/wiki/HTML_sanitization). If you want to include CSS or JavaScript, do so in **Appearance > CSS, JS, HTML** instead.
