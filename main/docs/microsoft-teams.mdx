Get ReadMe notifications as direct messages in Microsoft Teams by having a ReadMe admin connect your Microsoft tenant (your organization's Microsoft 365 environment) on the Integrations page, then connecting your own account through the ReadMe Inbox. Once connected, use inbox preferences to choose which notifications go to Teams.

## 1\. Connect your Microsoft tenant

A ReadMe admin completes this step once for the project:

1. In your ReadMe project, open **Settings → Integrations** and navigate to **Microsoft Teams**.
2. Click **Add to Microsoft Teams** and consent on Microsoft’s admin consent screen.
3. You will be automatically redirected to the ReadMe **Integrations** page and receive confirmation that you’re connected.

<Callout>
  ### Microsoft Teams App Package

  Some organizations block Teams apps from other providers by default. If your organization does, ReadMe displays an additional step:

  1. Click **App package** to download the ReadMe Teams app as a `.zip` file.
  2. In the Microsoft Teams admin center, approve the ReadMe app or upload the package.
  3. Return to ReadMe. When the availability check succeeds, the step changes to <strong>ReadMe app is available to Teams members.</strong>
</Callout>

## 2\. Connect your account

Once any project you are a member of connects a Microsoft tenant, complete these steps for your own account to receive Teams direct messages:

1. Open the ReadMe notification inbox using the bell icon at the bottom of the sidebar or in the dashboard navigation bar.
2. Click the gear icon in the inbox header to open **Preferences**.
3. Under Global Settings, find the Microsoft Teams tile labeled **Sync to your personal Microsoft Teams messages**.
4. Select the desired Microsoft tenant and click **Connect**. ReadMe finds your Teams account by email, installs the ReadMe app for you, and starts sending you direct messages.

## Optional: Choose which notifications go to Teams

In the inbox under **Preferences**, **for each notification type, there** is a channel control for <strong>MS Teams.</strong>  It remains unavailable until you connect your Teams account through the inbox. 

Once connected, you can send selected notifications to Teams and leave others in-app or email only.

## Troubleshooting

- <strong>Email mismatch:</strong> If you see **We couldn't find a Microsoft Teams account matching your email**, check that your ReadMe and Teams account emails match.
- <strong>Notifications turned off:</strong> If you opted out of all notifications, turn them back on before connecting Teams.

---

## FAQ

<Expandable title="How do I disconnect the Teams integration?">
  A ReadMe admin can open **Settings → Integrations → Microsoft Teams** and click **Disconnect**. This stops Teams notifications for everyone connected through that tenant. To resume delivery, an admin must connect the tenant again.
</Expandable>
