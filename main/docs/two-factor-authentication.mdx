  ReadMe strongly recommends enabling two-factor authentication (2FA) for an additional layer of security on your account.
</Callout>

ReadMe supports two-factor authentication (2FA). When logging into ReadMe with 2FA enabled on your account, you'll be required to enter a code from an authenticator app in addition to your password. We support any authenticator app that uses the <strong>TOTP (time-based, one-time password)</strong> algorithm.

## Enabling Two-Factor Authentication

To enable 2FA, navigate to the <strong>[Edit profile](https://dash.readme.io/user/edit)</strong> settings in the dashboard, locate the **Two Factor Auth** section, click **Enable**, and follow the instructions.

## Backup Codes

When setting up 2FA, you'll be prompted to save 10 backup codes. These **one-time-use** backup codes can be used to log you into ReadMe if you are unable to access 6-digit codes from your authenticator app.

> ⚠️ Keep your backup codes safe!
> 
> Remember that these backup codes are **one-time-use**—so if you just have a few (or zero) remaining, you can generate new ones in the [profile settings](https://dash.readme.io/user/edit) by clicking the **View Backup Codes** button. Generating new backup codes will invalidate your old ones!
> 
> If you cannot access your authenticator app and you've lost your backup codes, please contact us at [support@readme.io](mailto:support@readme.io).

## Recommended Authenticator Apps

We recommend [1Password](https://1password.com/), which allows you to [access one-time passwords](https://support.1password.com/one-time-passwords/) via a web browser extension, and desktop and mobile applications.

Other recommended apps include [Google Authenticator](https://support.google.com/accounts/answer/1066447), [Microsoft Authenticator](https://www.microsoft.com/en-us/account/authenticator), and [Authy](https://authy.com/download/).
