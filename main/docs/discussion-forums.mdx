The Support forum allows users to interact with each other to answer questions and learn to use your API or documentation in new ways!

1. To ask a new question, click on the **Ask a Question** button. This requires the user to sign-in or sign-up for a ReadMe account.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793774467550-5y9up4i4lzx-ba6e2a57ec4cc44f67ba71d751d2d48a29a27c62fb9be8d323af06ad39762d65-2cef80ba88eaca549676999349697793.png?fm=auto&auto=compress%2Cformat" alt="" />

2. Fill out the question form:

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793774473324-qle029ft3y-87710622cce7caded7e5c8ad057f006b29d00bc98adf0aa003eb7f016e580a93-208114dd32f365dcbab62b3ec33679db.png?fm=auto&auto=compress%2Cformat" alt="" />

The Discussions section in your developer hub features a version of our Markdown editor, allowing anyone submitting questions to include links, code samples, checklists, etc.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793774474274-1dfyzlyn18xh-029faef-new_Editor_in_discussions.gif?fm=auto&auto=compress%2Cformat" alt="" />

3. Your new question shows up at the top of the selected category. Other users can then *upvote* a question, in the top left of the page or *respond* to the question, at the bottom of the page. *Users can also vote from the forum page*

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793774476141-jzlyiqg4rzf-2f760169cbae852f356bf5a2602f2a3a716b01b7597d00113ed740be7c4f811f-948a009d27dc9e87b2dabef955f23aca.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Admins can mark a question as solved when a good response has been posted.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793774476491-v7b61m0iuy-2e5c5d22f2d3cbb482e630c50d64020f8d1511c48c316c9b9a58805869fce2fb-36b41e4a2bd4153acf033221d64098f0.png?fm=auto&auto=compress%2Cformat" alt="" />

5. Questions that have been solved show with a <strong>Answered!</strong> box on the forum page.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793774480557-z0b8kfwz3nk-89b809cb482a0ac889c8dc7cba33bf04495699ce64ad9465a228e8ef177efc79-50b22d26d41b09172e823ae709adb5ce.png?fm=auto&auto=compress%2Cformat" alt="" />

# Notifications

The Project Admins will get a notification on any new posts. You as the poster, will get a notification if anyone responds to your post. Anyone who responds to your post will get subsequent notifications on any new responses.
