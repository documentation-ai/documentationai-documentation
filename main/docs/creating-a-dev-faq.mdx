*Create an FAQ to help your users find the most useful questions*

# Create an FAQ

Admins can create an FAQ by adding any question from the forum, or by creating their own question and adding it. The FAQ is then displayed in the left hand menu.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793774509370-zy849f8xloh-bdfb132f146c30a9edc2231d55c84f608ebe2d02a8b24b50d65afbad76ccd973-4cb66049b20bdbd64872f67ea9d3d879.png?fm=auto&auto=compress%2Cformat" alt="" />

# Add a Question

Make sure you are logged in as an Admin, then find the "Add to FAQ" button for each question.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793774509485-imk1fz64gkd-e029d0e672bcc9133c3dbf01b240081026b99ee753e87c1109137234c278f95c-f9711bf73f44395e3c1766fc5d64e8f0.png?fm=auto&auto=compress%2Cformat" alt="" />

Once a question is added, Admins may remove comments to show the most helpful response or add their own.

Admins can also add their own questions by clicking <strong>"Ask a Question"</strong> to create their own question, then using the same process.

# Remove a Question

If a question has been added to the FAQ, the button will change to "Remove from FAQ". Click it to do that!

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793774513595-egazd85v3dd-eaeb9b17fadd93cda0b0cc70d9825063f500083e0c99cf30bf1f9ad845750fe0-7c58535c7dfd16894f67d4ba4f9962fa.png?fm=auto&auto=compress%2Cformat" alt="" />

# Disabling the FAQ

The FAQ can be disabled by removing all of the added FAQ questions. Simply click on each question, and select <strong>"Remove from FAQ"</strong>. When there are no questions left, the FAQ link will disappear.
