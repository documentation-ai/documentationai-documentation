The Google site verification integration lets you verify your site on ReadMe.

Simply copy the string in your meta tag using the [HTML tag method](https://support.google.com/webmasters/answer/35179?visit_id=1-636531454749772230-4021628945&rd=1), then navigate to **Settings > Integrations** and enter the string in **Google Site Verification**.
