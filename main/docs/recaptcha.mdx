Enabling reCaptcha within ReadMe will set up reCaptcha within the discussion forums. It will be implemented when a user comments on a discussion, or when someone creates a new post.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793774170356-7uc9xicynlo-4ffc5d0-Screen_Shot_2018-11-21_at_2-29-17_PM.png?fm=auto&auto=compress%2Cformat" alt="" />

To enable reCaptcha, head over to the [Google Admin panel](https://www.google.com/recaptcha/admin#list) and create a key pair. We support Google's Invisible reCaptcha v2, so ensure that the keys created are for this particular strategy.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793774170670-kiagrx5ldrq-e3b4371b9050a79ed6e7b77b9f0c7c00055cd57cdf1c99850b10c32b7e7c5bbc-b65b1e51d0cc8a5a228ce10ffad482bf.png?fm=auto&auto=compress%2Cformat" alt="" />

Once you've acquired the keys (site and secret), head over to the integrations page in the ReadMe dashboard, and set them. It's important that both keys be applied.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793774172752-3kakd5dwkzo-9b7bee533e5d7dfd50ecb9fa9ce352b684b9f6f0d9d7d12b3e5035c9c4d13411-3f25068d2b80ae39666b1458a4bf0b3f.png?fm=auto&auto=compress%2Cformat" alt="" />
