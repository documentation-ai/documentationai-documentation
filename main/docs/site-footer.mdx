## Remove the ReadMe Logo

Go to **Appearance > Footer** to hide the ReadMe logo in your documentation sidebar.

## Custom Footer HTML

You can add custom HTML to the footer from **Appearance > Footer**. The footer accepts raw HTML and renders it across all documentation pages.
