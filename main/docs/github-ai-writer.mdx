The AI Writer brings documentation into the tools your team already uses. Instead of switching context to update docs, your team can trigger documentation changes directly from GitHub pull requests or Slack conversations. Every change lands on a [review branch](/main/docs/branches) so nothing goes live without your approval.

## Integrations

<Columns cols={2}>
  <Card title="GitHub AI Writer" href="doc:github-ai-writer-setup" icon="fa-brands:github">
    Watches your pull requests and proposes doc updates when code changes affect your documentation. Install it on your repos and let it draft the changes for you.
  </Card>

  <Card title="Slack AI Writer" href="doc:slack-ai-writer" icon="fa-brands:slack">
    Create, edit, and manage documentation pages directly from Slack. Use slash commands to check metrics, manage branches, and keep your docs current without leaving the conversation.
  </Card>
</Columns>
