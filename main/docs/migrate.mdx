## Create a project

It’s easy to create your first ReadMe project. You can do this either through the ReadMe web interface, or via your AI Agent of choice.

- From your AI agent

  - Install the [ReadMe MCP](/main/docs/readme-mcp) and agent skills
  - Tell your agent to make your account and first project project.
- Through ReadMe's web interface:

  - [Sign Up](https://dash.readme.com/signup) with your work email
  - Create a project for your organization

## Recommended setup

ReadMe makes it easy to setup starting from our Starter plan. You can start with these steps or complete them at anytime while you’re importing content.

- Connect to GitHub or GitLab to [make it easy to import existing Markdown files](#add-your-content-from-git).
- Upload your logo and set your brand colors to personalize your docs.
- Set up a [custom domain](/main/docs/setting-up-custom-domain).
- Invite [teammates](/main/docs/manage-team).

Consider our Pro or Enterprise plans if:

- You need to connect to your [SAML provider to manage teammates](/main/enterprise/setting-up-sso).
- You want to ensure doc quality and [collaboration through branches](/main/docs/branches).
- You want to customize your docs using [custom CSS or JS](/main/docs/custom-css-and-javascript).

## Importing from a website

Use [our importer](https://readme.com/importer) to drop in a URL to your existing docs, upload an OpenAPI spec or markdown files of your content. We'll build your ReadMe project automatically.

For new/existing projects you can also use the [ReadMe MCP](/main/docs/readme-mcp) and agent skills to import content from existing websites; it can be helpful to tell your agent to copy branding from your existing website.

## Add your content manually

If you’ve decided to start fresh, you can start adding content manually. It’s a good time to start new docs with intention, without any baggage or out-dated content.

If you have an OpenAPI Specification (OAS) file that defines your API, you can upload it by navigating to edit mode, and then API Reference. From there, you can provide a URL for import, or upload the file from your computer.

For all other content:

1. Navigate to edit mode in the top navigation bar to start editing your docs
2. Add new pages in the left-hand sidebar
3. Add content (you can paste Markdown)

These actions are also possible via the [ReadMe MCP](/main/docs/readme-mcp) server; including OAS file upload.

## Add your content from Git

Once you’ve [connected your project to Git](/main/docs/bi-directional-sync), you can upload Markdown files locally or from your Git provider. ReadMe can parse files organized like so:

```text
📂 project
├── 📁 changelogs
├── 📁 custom_blocks
├── 📁 custom_pages
├── 📁 docs
│   ├── 📂 category-folder
│   │   ├── 📄 page.mdx
│   │   └── 📃 _order.yaml
│   └── 📃 _order.yaml
├── 📁 recipes
└── 📁 reference
```

For your first import:

- `docs`: Contains your main documentation content, organized in categories.
- `reference`: Contains API reference documentation.
- `changelogs`: Contains your Changelog entries, one flat Markdown file per entry.

Markdown files use required frontmatter to store important information about your docs:

```text
---
title: string # Title of the page
excerpt: string # Text displayed under title
deprecated: boolean # Mark page as deprecated
hidden: boolean # Visibility of page
category: string # Category page is organized in
metadata:
  title: string # SEO title
  description: string # SEO description
  keywords:
    - string
  robots: index | noindex # Whether this page should be indexed
  image: url

# For API Reference pages only
api:
  file: string # OAS file name ("hoot.json")
  operationId: string # Endpoint ID ("get_owls")
  webhook: boolean # If endpoint is a webhook
---
```

ReadMe will generate your `_order.yaml` files to control page order as you save changes on the platform.

## Migrate with an AI coding agent

Connect Claude Code, Cursor, Codex, or another AI coding agent to [ReadMe's MCP server](/main/docs/readme-mcp) with ReadMe's agent skills, and point it at your existing docs: a repository, exported files, or a public site. 

The agent can create your project if you're new to ReadMe, and perform the vast majority of readme operations. This includes creating and editing content, configuring styling and general project setting, import content from existing websites and more.

You can also use the ReadMe MCP to manage a [Bi-Directional sync](/main/docs/bi-directional-sync) repository; however, the MCP server cannot connect the repository to ReadMe for you. Connect your documentation repository before making any edits.
