Get the pages that exist within a category in your ReadMe project. Pages nested deeper than the 5 levels the rendered sidebar shows are returned too, up to 100 levels deep.

<Callout kind="info">
  This route is only available to projects that are using [ReadMe Refactored](https://docs.readme.com/main/docs/welcome-to-readme-refactored).
</Callout>
