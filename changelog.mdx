<Update label="2026-08-28" description="Collaboration, Analytics, Agent Connectors & more" tags={["release"]}>

### New Features

- **Real-time collaboration** — Multiple editors can work on the same documentation simultaneously with live cursors, inline comments with reply and resolve, and a notifications bell for mentions and replies.
- **Redesigned analytics** — A new Overview dashboard shows traffic, feedback, and AI assistant metrics at a glance, with period-over-period comparison and drill-down by category (people, AI agents, bots).
- **Agent settings page** — Centralized connector management for GitHub, Jira, and Confluence. Configure custom agent instructions for brand voice and terminology.
- **MCP server redesign** — Separate Authoring MCP for Claude Desktop and Cursor and Reader MCP for docs consumers panels with machine-to-machine credential management.
- **GitLab support** — Connect GitLab repositories alongside GitHub.
- **Hosted OpenAPI specs** — Add API reference specs from a URL instead of committing a file directly.
- **SEO and meta controls** — Set meta titles, descriptions, canonical URLs, open graph images, and JSON-LD structured data per page, group, or navigation item.
- **Migrate to your own repo** — Wizard to move from the hosted repository to your own GitHub or GitLab repository.

### Updates

- **AI assistant improvements** — Loading skeletons while conversation history loads, automatic resumption of in-progress AI replies after page refresh, and more reliable attachment handling.
- **Editor UX polish** — Refined sidebar active states, consistent button styling, and toast notifications repositioned to the bottom-right with a close button.
- **Branch selector** now preserves query parameters when switching branches, keeping collaborative sessions intact.

### Bug Fixes

- Fixed navigation sidebar performance — large documentation trees no longer cause UI blocking during editing.
- Fixed organization selection page loading twice on mount.
- Fixed editor redirect for repositories that deploy from a non-default branch.


</Update>
