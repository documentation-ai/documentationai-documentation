## Recent Updates

Stay informed about the latest releases of WP Travel Engine. You can check your current version in the WordPress admin under **Plugins > Installed Plugins**.

<Callout kind="info">
  Always back up your site before updating. Test on a staging environment if possible.
</Callout>

## Upgrade Process

<Steps>
  <Step title="Check Compatibility" icon="shield">
    Review the update notes below for any breaking changes or addon compatibility.
  </Step>
  <Step title="Backup Site" icon="database">
    Use a plugin like UpdraftPlus or your hosting backup tool.
  </Step>
  <Step title="Update Plugin" icon="download">
    Go to **Plugins > Installed Plugins** and click **Update Now**.
  </Step>
  <Step title="Test Trips" icon="check-circle">
    Verify trip pages, bookings, and itineraries function correctly.
  </Step>
</Steps>

## Latest Releases

<Update label="2026-09-07" description="Media Manager" tags={["feature", "improvement", "bugfix"]}>

## New Features

- **Replace images without breaking links** — Swap a media asset with a new file while keeping the same URL. Every page that references the image automatically shows the new file, no manual edits required.
- **Rename files before uploading from the editor** — When inserting media via the slash command picker, you can now edit the filename before it uploads. The original file extension is preserved.
- **Media library accessible from the editor sidebar** — The Media tab is now available in the editor's secondary navigation, so you can browse and manage assets without leaving the page you're editing.

## Improvements

- **Upload progress visibility** — Large file uploads now show a percentage in the progress toast, so you always know the upload is working instead of guessing.
- **Non-blocking replace flow** — The media detail panel closes immediately after you choose a replacement file, letting you return to the library while the replacement continues in the background.
- **CDN-aware image refreshing** — Replaced images now update automatically once the CDN confirms the new file is live. A "Replacing across your documentation" overlay appears on the old image during propagation, and the preview refreshes on its own when complete.
- **Replacement state survives page reloads** — If you refresh the page during a CDN propagation, the replacement status is preserved and continues tracking until the new file is confirmed live.

## Bug Fixes

- **Fixed stale image previews after replacement** — Previously, browser and CDN caching could show the old image even after a successful replacement. Replaced assets now refresh reliably across the media library and editor.
- **Fixed stale video and PDF poster images** — Replacing a video or PDF now regenerates its poster image, so the thumbnail matches the new file.
- **Fixed upload failures for generated posters and onboarding logos** — Corrected content-type and caching headers on presigned uploads, preventing failures for auto-generated media assets.

</Update>
