## Recent Updates

Stay informed about the latest releases of WP Travel Engine. You can check your current version in the WordPress admin under **Plugins > Installed Plugins**.

<Callout kind="info">
  Always back up your site before updating. Test on a staging environment if possible.
</Callout>

## Upgrade Process

<Steps>
  <Step title="Check Compatibility" icon="shield">
    Review the update notes below for any breaking changes or addon compatibility.
  </Step>
  <Step title="Backup Site" icon="database">
    Use a plugin like UpdraftPlus or your hosting backup tool.
  </Step>
  <Step title="Update Plugin" icon="download">
    Go to **Plugins > Installed Plugins** and click **Update Now**.
  </Step>
  <Step title="Test Trips" icon="check-circle">
    Verify trip pages, bookings, and itineraries function correctly.
  </Step>
</Steps>

## Latest Releases

<Update label="2026-10-21" description="Context Repositories & Branch Selection" tags={["feature", "improvement", "bugfix"]}>

## New Features

- **GitLab context repositories** — Connect GitLab projects as read-only AI context sources alongside GitHub repositories. The agent reads your code but never writes to the project.
- **Branch selection for context repositories** — Choose which branch the AI reads for each connected repository. Set a default in Agent settings, then override it per chat or per automation.
- **Branch selection in automations** — Automation connectors now include inline branch pickers for each included repository.

## Improvements

- Context repository connectors are now grouped by provider (GitHub, GitLab) across Agent settings, chats, and automations for clearer organization.
- Branch lists preload when the repository dialog opens, with search and per-repository refresh for quick selection.
- Code analysis results now display the correct provider icon (GitHub or GitLab) based on the repository's source.
- Each provider supports up to 10 context repositories, with a visible selection counter.

## Bug Fixes

- Branch selections made during chat loading are no longer overwritten by stale server data.
- Newly added GitLab repositories no longer show an empty branch picker before branches load.
- GitLab connections no longer create unusable excess connectors when the repository limit is reached.
- Duplicate success notifications when connecting a GitLab project have been removed.
- Swapping repositories after reaching the 10-repository limit now works reliably.

</Update>

- Optimized itinerary rendering for better performance on mobile devices

- Fixed seat allocation issues when using FSD addon
- Resolved image gallery upload errors in multilingual setups
