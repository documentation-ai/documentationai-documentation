## Recent Updates

Stay informed about the latest releases of WP Travel Engine. You can check your current version in the WordPress admin under **Plugins > Installed Plugins**.

<Callout kind="info">
  Always back up your site before updating. Test on a staging environment if possible.
</Callout>

## Upgrade Process

<Steps>
  <Step title="Check Compatibility" icon="shield">
    Review the update notes below for any breaking changes or addon compatibility.
  </Step>
  <Step title="Backup Site" icon="database">
    Use a plugin like UpdraftPlus or your hosting backup tool.
  </Step>
  <Step title="Update Plugin" icon="download">
    Go to **Plugins > Installed Plugins** and click **Update Now**.
  </Step>
  <Step title="Test Trips" icon="check-circle">
    Verify trip pages, bookings, and itineraries function correctly.
  </Step>
</Steps>

## Latest Releases

<Update label="2025-06-18" description="Documentation.AI" tags={["feature", "improvement"]}>

## New Features

- **External Sources**: Let the AI Assistant answer from PDFs and websites alongside your published documentation. Add up to 10 PDFs at once, with a 50 MB limit per PDF, using drag-and-drop. Add website sources by entering a URL and selecting specific pages from a crawl preview. Set source priority, control visibility as public or protected, and configure access roles for each source.
- **Website refresh schedules**: Choose weekly, monthly, or manual refreshes for website sources. Use **Refresh now** to start an immediate refresh and view a summary of newly found or removed pages.
- **Source status monitoring**: Track each source as Queued, Processing, Ready, or Failed. Expand a source to view its latest processing steps and failure explanation.

## Improvements

- **AI Assistant settings redesign**: Settings are organized into navigable sections: Behavior, Knowledge, and Security. Behavior includes Controls, Custom Instructions, Conversation Starters, and Response Handling. Knowledge includes External Sources, and Security includes Bot Protection. The selected section appears in the URL for easy sharing.
- **Assistant Mode cost guidance**: Assistant Mode now displays credit usage. Pro mode uses 10 credits per answer, and Lite mode uses 1 credit per answer.
- **Bot Protection pane**: The Invisible Captcha setting moved from the general controls page into a dedicated Security section.

</Update>
