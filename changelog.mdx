## Recent Updates

Stay informed about the latest releases of WP Travel Engine. You can check your current version in the WordPress admin under **Plugins > Installed Plugins**.

<Callout kind="info">
  Always back up your site before updating. Test on a staging environment if possible.
</Callout>

## Upgrade Process

<Steps>
  <Step title="Check Compatibility" icon="shield">
    Review the update notes below for any breaking changes or addon compatibility.
  </Step>
  <Step title="Backup Site" icon="database">
    Use a plugin like UpdraftPlus or your hosting backup tool.
  </Step>
  <Step title="Update Plugin" icon="download">
    Go to **Plugins > Installed Plugins** and click **Update Now**.
  </Step>
  <Step title="Test Trips" icon="check-circle">
    Verify trip pages, bookings, and itineraries function correctly.
  </Step>
</Steps>

## Latest Releases

<Update label="2025-07-17" description="Platform Update" tags={["feature"]}>

## New Features

- **Documentation.AI sign-in for access control** — Documentation owners can now require readers to sign in with their Documentation.AI account to view protected documentation. Access is managed through organization membership — no separate passwords or external identity providers needed.
- **Reader sign-in page** — Readers accessing protected documentation are redirected to a dedicated sign-in page where they authenticate with their Documentation.AI account. The page shows which documentation they're signing in to and supports switching accounts if access is denied.

## Improvements

- Documentation.AI sign-in is available on all plans, including Starter.
- Reader MCP setup instructions now reference Documentation.AI accounts for authenticated endpoints. See [connecting AI assistants via MCP](/connect-ai-assistants-via-mcp-with-wp-travel-engine).
- Readers receive clear messages when access is denied, including guidance to contact an administrator.

</Update>

<Update label="2024-10-15" description="v6.2.0" tags={["feature", "bugfix"]}>

## New Features

- Added support for dynamic trip duration display on single trip pages using `[wpte_trip_duration]`
- Enhanced trip gallery with lightbox and zoom functionality

## Improvements

- Optimized itinerary rendering for better performance on mobile devices
- Added compatibility with latest WordPress block editor patterns

## Bug Fixes

- Fixed seat allocation issues when using FSD addon
- Resolved image gallery upload errors in multilingual setups

</Update>

<Update label="2024-09-20" description="v6.1.5" tags={["bugfix", "improvement"]}>

## Improvements

- Improved booking capacity calculations for group trips
- Better integration with social login providers (Google, Facebook)

## Bug Fixes

- Fixed user dashboard pagination for booked trips
- Corrected date and price info syncing across trip updates

</Update>

<Update label="2024-08-10" description="v6.1.0" tags={["feature", "breaking"]}>

## New Features

- Redesigned user dashboard with customizable widgets
- New trip includes/excludes metabox for easier management

## Breaking Changes

- Updated shortcode attributes: Use `duration="dynamic"` instead of legacy format
- Requires PHP 8.0+ for new booking engine

## Bug Fixes

- Patched general info tab validation errors
- Fixed trip overview info display on archive pages

</Update>
