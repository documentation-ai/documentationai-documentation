This theme provides a `@theme/SearchBar` component that integrates with Algolia DocSearch easily. Combined with `@docusaurus/theme-classic`, it provides a very easy search integration. You can read more on [search](/docs/search) documentation.

<Tabs>
  <Tab title="npm">
    ```
    npm install --save @docusaurus/theme-search-algolia
    ```
  </Tab>

  <Tab title="Yarn">
    ```
    yarn add @docusaurus/theme-search-algolia
    ```
  </Tab>

  <Tab title="pnpm">
    ```
    pnpm add @docusaurus/theme-search-algolia
    ```
  </Tab>

  <Tab title="Bun">
    ```
    bun add @docusaurus/theme-search-algolia
    ```
  </Tab>
</Tabs>

This theme also adds search page available at `/search` (as swizzlable `SearchPage` component) path with OpenSearch support. You can change this default path via `themeConfig.algolia.searchPagePath`. Use `false` to disable search page.

<Callout kind="tip">
  tip

  If you have installed `@docusaurus/preset-classic`, you don't need to install it as a dependency.
</Callout>
