An [SVGR](https://react-svgr.com/) plugin to transform SVG files into React components automatically at build time.

## Installation

<Tabs>
  <Tab title="npm">
    ```
    npm install --save @docusaurus/plugin-svgr
    ```
  </Tab>

  <Tab title="Yarn">
    ```
    yarn add @docusaurus/plugin-svgr
    ```
  </Tab>

  <Tab title="pnpm">
    ```
    pnpm add @docusaurus/plugin-svgr
    ```
  </Tab>

  <Tab title="Bun">
    ```
    bun add @docusaurus/plugin-svgr
    ```
  </Tab>
</Tabs>

<Callout kind="tip">
  tip

  If you use the preset `@docusaurus/preset-classic`, you don't need to install this plugin as a dependency.

  You can configure this plugin through the [preset options](/docs/using-plugins#docusauruspreset-classic).
</Callout>

### Example configuration

You can configure this plugin through plugin options.

<Tabs>
  <Tab title="Preset options">
    If you use a preset, configure this plugin through the [preset options](/docs/using-plugins#docusauruspreset-classic):

    docusaurus.config.js

    ```
    module.exports = {  presets: [    [      '@docusaurus/preset-classic',      {        svgr: {          svgrConfig: {            /* SVGR config */          },        },      },    ],  ],};
    ```
  </Tab>

  <Tab title="Plugin options">
    If you are using a standalone plugin, provide options directly to the plugin:

    docusaurus.config.js

    ```
    module.exports = {  plugins: [    [      '@docusaurus/plugin-svgr',      {        svgrConfig: {          /* SVGR config */        },      },    ],  ],};
    ```
  </Tab>
</Tabs>
