The GitBook API provides developers with a powerful and flexible way to interact with GitBook's platform programmatically. It offers endpoints to manage content and integrate GitBook functionalities into external applications.

This API is RESTful and supports standard HTTP methods like `GET`, `POST`, `PATCH`, and `DELETE`.

### API tasks

Use these API references to complete common tasks:

| Task | API reference |
| --- | --- |
| Manage organizations | [Organizations](/docs/developers/gitbook-api/api-reference/organizations) |
| Create and manage spaces | [Spaces](https://gitbook.com/docs/developers/gitbook-api/api-reference/spaces) |
| Create and manage collections | [Collections](https://gitbook.com/docs/developers/gitbook-api/api-reference/collections) |
| Create and manage published docs sites | [Published docs sites](/docs/developers/gitbook-api/api-reference/docs-sites) |
| Manage members, teams, and permissions | [Organization members](/docs/developers/gitbook-api/api-reference/organizations/organization-members) |
| Import and export pages, files, and reusable content | [Content import and export](https://gitbook.com/docs/developers/gitbook-api/api-reference/imports) |
| Create and manage change requests | [Change requests](https://gitbook.com/docs/developers/gitbook-api/api-reference/change-requests) |
| Create and manage comments | [Comments](https://gitbook.com/docs/developers/gitbook-api/api-reference/change-requests/change-request-comments) |
| Configure custom hostnames, URLs, and search | [Site customization](https://gitbook.com/docs/developers/gitbook-api/api-reference/custom-hostnames) |
| Monitor content performance | [Analytics](https://gitbook.com/docs/developers/gitbook-api/api-reference/docs-sites/site-insights) |
| Manage integrations and OpenAPI documentation | [Integrations](https://gitbook.com/docs/developers/gitbook-api/api-reference/integrations) |

### OpenAPI spec

You can view GitBook’s hosted OpenAPI spec used to generate our API docs [here](https://api.gitbook.com/openapi.json). Learn more about creating your own API references in our [product docs](/docs/create-content/openapi).
