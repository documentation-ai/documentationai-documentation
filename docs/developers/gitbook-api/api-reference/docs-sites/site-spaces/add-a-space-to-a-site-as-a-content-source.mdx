For the complete documentation index, see [llms.txt](https://gitbook.com/docs/llms.txt). This page is also available as [Markdown](/docs/developers/gitbook-api/api-reference/docs-sites/site-spaces/add-a-space-to-a-site-as-a-content-source).

Pass an existing space ID to link it, or pass `null` to create and link a new space. New spaces start with a blank page unless a template is provided or `empty` is `true`, which creates the space with no page at all (use it when you are about to add the pages yourself).

Available in MCP

post

Authorizations

AuthorizationstringRequired

Bearer authentication header of the form Bearer &lt;token>.

Path parameters

organizationIdstringRequired

A unique entity identifier

Pattern: `^[a-zA-Z0-9_-]+$`

siteIdstringRequired

The unique id of the site

Header parameters

preferstring · enumOptional

Control whether a successful response includes the updated resource representation.

Possible values:

Body

spaceIdstring · nullableRequired

Pass the ID of an existing space or `null` to create a new space.

sectionIdstringOptional

ID of the section to add the space to. If not provided, the space will be added to the default section or at the root level if the site has no sections.

draftbooleanOptional

Whether the site space should be created as draft. Defaults to false. Editors can set this to true to create draft content on a non-empty site. Creating live content and adding the first content require Creator permission.

Default: `false`

pageIdstring · nullableOptional

Custom home page within an existing space, rendered at the site space's path root instead of the space's default landing page. Providing it when `spaceId` is `null` returns a 400 error.

emptybooleanOptional

Create the new space without any content, not even a blank page. Useful when the content is about to be populated, for example by an import. Only valid when `spaceId` is `null` and no template is provided.

Default: `false`

titlestring · min: 2 · max: 128Optional

Site-specific title override for the variant. Also used as the space title when `spaceId` is `null` and no template is provided.

Responses

201

Space added to the site

application/json

204

Space added to the site without returning its representation
