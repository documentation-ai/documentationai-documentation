For the complete documentation index, see [llms.txt](https://gitbook.com/docs/llms.txt). This page is also available as [Markdown](/docs/developers/gitbook-api/api-reference/organizations/list-all-style-guides-in-an-organization).

Lists every style guide (a space holding a team's writing style guide) in the organization, along with every site that references each one. Style guides that are not referenced by any site are still returned with an empty `sites` list.

Available in MCP

get

Authorizations

AuthorizationstringRequired

Bearer authentication header of the form Bearer &lt;token>.

Path parameters

organizationIdstringRequired

A unique entity identifier

Pattern: `^[a-zA-Z0-9_-]+$`

Responses

200

OK

application/json

get/orgs/&#123;organizationId&#125;/styleguides

```
GET /v1/orgs/{organizationId}/styleguides HTTP/1.1
Host: api.gitbook.com
Authorization: Bearer YOUR_SECRET_TOKEN
Accept: */*
```
