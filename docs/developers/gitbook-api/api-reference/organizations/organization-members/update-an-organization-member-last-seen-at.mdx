**POST** `/orgs/{organizationId}/ping`

**Parameters**

<ParamField header="Authorization" param-type="string" required={true} />

<ParamField path="organizationId" param-type="string" required={true}>
  The unique id of the organization
</ParamField>

**Responses**

`200` Organization member has been updated. Optionally returns a JWT token to attach to the user.

<ResponseField name="gitbookVisitorClaims" field-type="string">
  A JTW token containing the claims to attach to this user.
</ResponseField>
