Available in MCP

get

Authorizations

AuthorizationstringRequired

Bearer authentication header of the form Bearer &lt;token>.

Query parameters

pagestringOptional

Identifier of the page results to fetch.

limitnumber · max: 1000Optional

The number of results per page

sortstring · enumOptional

The property to sort the list by. With `lastSeenAt`, only the organizations the user has opened are returned, most recently opened first. It returns at most `limit` items with no next page, and cannot be combined with `page`, because the order changes every time the user opens an organization.

Possible values:

Responses

200

OK

application/json

countnumberOptional

Total count of objects in the list

400

Bad Request

application/json

get/orgs

```
GET /v1/orgs HTTP/1.1
Host: api.gitbook.com
Authorization: Bearer YOUR_SECRET_TOKEN
Accept: */*
```
