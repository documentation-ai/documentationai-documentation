Ensure that the Docusaurus [`<Link>`](https://docusaurus.io/docs/3.1.1/docusaurus-core#link) component is used instead of `<a>` tags.

The `<Link>` component has prefetching and preloading built-in. It also does build-time broken link detection, and helps Docusaurus understand your site's structure better.

<a id="details"></a>

## Rule Details

Examples of **incorrect** code for this rule:

```
<a href="/page">go to page!</a><a href="https://x.com/docusaurus" target="_blank">X</a>
```

Examples of **correct** code for this rule:

```
import Link from '@docusaurus/Link'<Link to="/page">go to page!</Link><Link to="https://x.com/docusaurus">X</Link>
```
