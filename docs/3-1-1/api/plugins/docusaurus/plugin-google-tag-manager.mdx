A plugin for adding [Google Tag Manager (gtm.js)](https://developers.google.com/tag-platform/tag-manager) to a Docusaurus site. Use this plugin in conjunction with the standard [gtag plugin](/docs/3-1-1/api/plugins/docusaurus/plugin-google-gtag) for in-depth analysis of how users are using your site.

<Callout kind="tip">
  tip

  You can use [Google's Tag Assistant](https://tagassistant.google.com/) tool to check if tag manager is set up correctly!
</Callout>

<Callout kind="alert">
  production only

  This plugin is always inactive in development and **only active in production** to avoid polluting the analytics statistics.
</Callout>

## Installation

<Tabs>
  <Tab title="npm">
    ```
    npm install --save @docusaurus/plugin-google-tag-manager
    ```
  </Tab>

  <Tab title="Yarn">
    ```
    yarn add @docusaurus/plugin-google-tag-manager
    ```
  </Tab>

  <Tab title="pnpm">
    ```
    pnpm add @docusaurus/plugin-google-tag-manager
    ```
  </Tab>

  <Tab title="Bun">
    ```
    bun add @docusaurus/plugin-google-tag-manager
    ```
  </Tab>
</Tabs>

<Callout kind="tip">
  tip

  If you use the preset `@docusaurus/preset-classic`, you don't need to install this plugin as a dependency.

  You can configure this plugin through the [preset options](https://docusaurus.io/docs/3.1.1/using-plugins#docusauruspreset-classic).
</Callout>

### Example configuration

You can configure this plugin through preset options or plugin options.

<Callout kind="tip">
  tip

  Most Docusaurus users configure this plugin through the preset options.
</Callout>

<Tabs>
  <Tab title="Preset options">
    If you use a preset, configure this plugin through the [preset options](https://docusaurus.io/docs/3.1.1/using-plugins#docusauruspreset-classic):

    docusaurus.config.js

    ```
    module.exports = {  presets: [    [      '@docusaurus/preset-classic',      {        googleTagManager: {          containerId: 'GTM-12345',        },      },    ],  ],};
    ```
  </Tab>

  <Tab title="Plugin options">
    If you are using a standalone plugin, provide options directly to the plugin:

    docusaurus.config.js

    ```
    module.exports = {  plugins: [    [      '@docusaurus/plugin-google-tag-manager',      {        containerId: 'GTM-12345',      },    ],  ],};
    ```
  </Tab>
</Tabs>
