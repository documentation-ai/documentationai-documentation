This section is not going to be very structured, but we will cover the following topics:

[📄️ArchitectureHow Docusaurus works to build your app](/docs/3-1-1/advanced/architecture)

[📄️PluginsPlugins are the building blocks of features in a Docusaurus site. Each plugin handles its own individual feature. Plugins may work and be distributed as part of a bundle via presets.](/docs/3-1-1/advanced/plugins)

[📄️RoutingDocusaurus' routing system follows single-page application conventions: one route, one component.](/docs/3-1-1/advanced/routing)

[📄️Static site generationDocusaurus statically renders your React code into HTML, allowing faster load speed and better SEO.](/docs/3-1-1/advanced/ssg)

[📄️Client architectureHow the Docusaurus client is structured](/docs/3-1-1/advanced/client)

We will assume that you have finished the guides, and know the basics like how to configure plugins, how to write React components, etc. These sections will have plugin authors and code contributors in mind, so we may occasionally refer to [plugin APIs](/docs/3-1-1/api/plugin-methods) or other architecture details. Don't panic if you don't understand everything😉
