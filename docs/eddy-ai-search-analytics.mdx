The **Eddy AI - Assistive Search** analytics page gives you a complete picture of how readers interact with Eddy AI across your knowledge base, tracking conversations, query volumes, answered and unanswered searches, and reader feedback. Use this page to identify content gaps, measure AI search effectiveness, and take targeted actions to improve your documentation coverage.

To know more about the languages supported by Eddy AI, [click here](https://docs.document360.com/help/docs/ai-search-suite#multilingual-support-for-eddy-ai-search-suite).

 NOTE

Advanced Eddy AI analytics adds unanswered query scope analysis, topic topics, taxonomy, content utilisation, and query type breakdowns. If the **Try new Eddy AI analytics** option is available for your project, read [Advanced Eddy AI analytics](/docs/eddy-ai-search-analytics#advanced-eddy-ai-analytics). To check availability for your project, contact your Customer Success Manager or [Document360 support](mailto:support@document360.com).

---

## Why use Eddy AI search analytics

Use the Eddy AI search analytics page when you want to:

- **Identify unanswered queries** — find topics your readers search for but cannot find answers to, signalling content gaps.
- **Monitor AI search performance** — track answered vs. unanswered query trends over time to assess how well Eddy AI serves your readers.
- **Audit reader feedback** — review likes, dislikes, and feedback comments to evaluate the quality and relevance of AI-generated responses.
- **Investigate individual conversations** — drill into specific user interactions to validate citation accuracy and response quality.

## Access Eddy AI search analytics

1. Navigate to **Analytics** () in the left navigation bar in the Knowledge base portal.
2. In the left navigation pane, click **Eddy AI**. The **Eddy AI - Assistive Search** page appears.
3. By default, data for the **current month** is displayed.

<Image src="https://cdn.document360.io/860f9f88-412e-4570-8222-d5bf2f4b7dd1/Images/Documentation/eddy-ai-assistive-search-new%281%29.png" alt="Eddy AI dashboard displaying total conversations, queries, and feedback statistics." />

Click Try new Eddy AI analytics to access the new [advanced Eddy AI analytics](https://docs.document360.com/help/docs/eddy-ai-search-analytics#advanced-eddy-ai-analytics).

### Using filters to customize the data

By default, the page shows metrics for the current month. To adjust the timeframe or scope:

1. Click the **Month** filter dropdown.
2. Choose a predefined range (**This month**, **Last month**) or select **Custom** to specify a particular month. When using the **Custom** filter, you can select only the month from the calendar.
3. Click **Filter** to narrow results by application type: **All**, **Knowledge base site**, **Knowledge base widgets**, **Chatbot**, **Public API**, or extensions such as Freshdesk or Zendesk.

## Understanding the analytics page

### Metric tiles

The top of the page displays the following performance metrics as tiles:

| Field | Description |
| --- | --- |
| **Total conversations** | Total number of conversations in Eddy AI, where one or more queries count as a conversation. Available only in KB site 2.0. A single message is also counted as a conversation. |
| **Total queries** | Total count of individual questions asked to Eddy AI. Queries are individual questions within a conversation. |
| **Answered queries** | Total number of queries that returned a result. |
| **Unanswered queries** | Total number of queries that did not produce any results. |
| **Total likes** | Total number of likes received on search responses, indicating a satisfactory answer. |
| **Total dislikes** | Total number of dislikes received, indicating an unsatisfactory response. Dislike reasons include: difficult to understand, inaccurate or irrelevant content, incorrect sources/references/citations, missing information, don't like the style, and others (with a free-text comment). |
| **Total feedback** | Total number of feedback comments received for AI assistive search responses. |

 NOTE

If multiple chatbots are deployed, data from all chatbot instances is merged into a single result set. Similarly, data from all knowledge base widget instances is combined.

### Conversations

The **Conversations** section provides a detailed, tabular view of every user interaction — including the full query, response status, and any feedback received.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793778361613-lijxihk5i29-1_Screenshot-Eddy_ai_search_analytics_conversation_table.png?fm=auto&auto=compress%2Cformat" alt="Conversations table displaying user queries, response status, and feedback details." />

The table includes the following columns and controls:

a. **Search field** — enter a keyword or phrase to find a specific conversation or question.

b. **Conversations** — displays the first question of each conversation; subsequent questions are collapsed by default. Expand a row to view all questions, or click a query to open a side panel showing the full conversation, user information (if available), user group, and the date and time of the interaction.

 NOTE

If a conversation started in a previous month and continues into the current month, it is attributed to the month in which it started.

c. **Query topic** — topics are assigned from the popular queries list. At least 30 days of data is required to generate a query topic. Only the top 5 popular topics are displayed.

d. **Response** — indicates whether the query was answered () or unanswered ().

e. **Feedback icon** — shows whether feedback was a like () or dislike ().

f. **Feedback** — displays a **Feedback** tag if the query received feedback. Click to navigate to the [Eddy AI feedback manager](https://docs.document360.com/docs/en/eddy-ai-feedback) to view the full feedback details.

g. **User info** — for **Mixed** and **Private** projects, displays the name or email address of the user who submitted the query (when available). For JWT users without a name, the associated email address is shown if available. This identity is analytics metadata held within Document360; it is not sent to OpenAI as part of the query or response. See [Data privacy and security](https://docs.document360.com/help/docs/ai-assistive-search#data-privacy-and-security) in the Ask Eddy AI article for what is sent to OpenAI.

h. **User group** — displays the reader group or user group associated with the user, if applicable.

i. **Filter** — filter conversations by:

- **Response status**: All, Answered, or Unanswered.
- **Feedback**: All, None, Like, or Dislike. This covers feedback received on Eddy AI responses from the Knowledge base site, Widget, Chatbot, and Public API.
- **Query topic**: Filters queries from previous months (unavailable for the current month). Options include **Select all** (displays both five popular queries and five unanswered queries), **Popular queries**, and **Unanswered queries**.

j. **Export CSV** — download the filtered conversation data as a .csv file. Click the **Download** () icon to retrieve the last set of files exported.

 NOTE

When the [**Anonymize reader information**](https://docs.document360.com/docs/en/general-project-settings#analytics-settings) setting is enabled, reader-identifiable information linked to Eddy AI conversations is anonymised. User names, email addresses, and reader IDs will not appear in analytics or exports.

### Viewing Eddy AI source articles

When you expand a query in the **Conversations** section, the response displays numbered citations (e.g., 1 2 3) at the end. Hovering over a citation number reveals the article title; clicking it opens the source article in the Knowledge base site.

<Image src="https://cdn.document360.io/860f9f88-412e-4570-8222-d5bf2f4b7dd1/Images/Documentation/citation%20-%20apr%20patch.png" alt="Conversation panel showing numbered citations linking to source articles in the Knowledge base site." />

This lets you quickly validate the sources Eddy AI used to generate a response and identify content that may need to be updated. Citation links always point to the latest published version of the source article. If the article has since been deleted, the link will display an **Error 404** page.

 NOTE

Citation details are not available in OpenAPI or API documentation. They are only accessible from the Knowledge base portal or the Knowledge base site.

## Advanced Eddy AI analytics

Advanced Eddy AI analytics extends the Eddy AI analytics experience with deeper breakdowns of how readers use Eddy AI and where it falls short. Alongside query volumes and feedback, it groups queries into topics, classifies unanswered queries by whether your documentation was expected to cover them, and shows how much of your content Eddy AI draws on when generating responses.

 NOTE

Advanced Eddy AI analytics is available for select plans and must be enabled for your project. If you do not see the **Try new Eddy AI analytics** option on the **Eddy AI - Assistive Search** analytics page, contact your Customer Success Manager or [Document360 support](mailto:support@document360.com) to check availability for your project.

### What you can analyze

Use advanced Eddy AI analytics to answer questions such as:

- Of the queries Eddy AI could not answer, how many were **in scope**, meaning questions your documentation was expected to cover?
- Which **topics** are readers asking about most, and which of those topics are failing?
- What **types of messages** do readers send: questions, statements, troubleshooting requests, or commands?
- How much of your published content does Eddy AI actually draw on, and which articles does it cite most often?

### Open the advanced analytics page

1. Navigate to **Analytics** () > **Eddy AI** in the Knowledge base portal.
2. Click **Try new Eddy AI analytics**. The advanced analytics page appears, with three tabs: **Query analysis**, **Content utilization**, and **User interaction**.
3. By default, data for **Last month** is displayed. Use the month picker in the page header to select a different calendar month.

### Filters and navigation

- **Month** — data is shown for one whole calendar month at a time. Changing the month refreshes every panel on the page.
- **Workspace version and language** — data is scoped to the workspace version and language selected in the top bar. Switching either one refreshes every panel on the page.
- **Pagination** — the tables display 10 rows per page. Changing the month, version, language, or a filter returns each table to the first page.

### Things to know

- All data on this page is displayed in **UTC**, not your local time zone.
- Data is available for whole calendar months only. Weekly and custom date ranges are not supported.
- Advanced analytics data is processed monthly. If processing for the selected month is not yet complete, the panels display 0 and **No data available**.
- The tiles and charts refresh periodically, so they can briefly show lower values than the tables below them. If this happens, check again later in the day.
- Exporting charts and tables from the advanced analytics page is not available yet. To export conversation data, use **Export CSV** on the **Eddy AI - Assistive Search** analytics page.
- A newly created or copied project has no advanced analytics data until the first monthly processing completes for that project.

## Understanding AI credit usage and analytics

In some cases, the query count shown in Eddy AI search analytics may differ from the usage credits consumed under the Eddy AI feature. This can happen for two reasons:

1. **Multi-language projects** \- if your project supports multiple languages (for example, English and German), credits are consumed across all languages. However, the Analytics view for a single language shows only queries made in that language, which may appear lower than total credit usage.
2. **Non-chargeable interactions** \- simple greetings such as "Hi" or "Hello" are recorded in Analytics for completeness but do not consume credits. As a result, the query count in Analytics can be slightly higher than the number of credits used.<br /> If you reach the usage limit, contact support to update or verify your detailed usage data.

## Best practices

- **Review unanswered queries monthly** \- use the Unanswered queries section to identify recurring content gaps and update or create articles to address them.
- **Act on dislike feedback** \- check the Feedback chart regularly. Responses marked as "inaccurate" or "missing information" are the highest-signal items to investigate.
- **Cross-reference most-referenced articles** \- these articles carry the highest weight in Eddy AI responses. Ensure they are accurate, up to date, and comprehensive.
- **Use the Conversations table to validate citations** \- expand individual queries to confirm that source articles are correct and current. Deleted source articles result in broken citation links.
- **Start with in-scope unanswered queries** \- if advanced Eddy AI analytics is available for your project, work through the in-scope unanswered topics first. These represent questions your documentation was expected to answer.

## FAQ

<Expandable title="Why am I unable to filter the data on a weekly basis?">
  Popular queries and unanswered search keywords are derived from algorithmic grouping methods that require at least 30 days of data to categorise keywords based on response frequency. Weekly filtering is not supported because the dataset is too small for accurate grouping.
</Expandable>

<Expandable title="How do I resolve queries for which no response is generated?">
  Review the keywords listed in the Unanswered queries section. Use those keywords to identify relevant articles and update or create content that directly addresses the topic. You can also use the [Eddy AI feedback manager](https://docs.document360.com/docs/en/eddy-ai-feedback) to track unanswered query feedback to resolution.
</Expandable>

<Expandable title="How does Eddy AI conversation analytics work when a conversation spans multiple languages?">
  The conversation is recorded in the conversations table for each language used. However, specific metrics such as total searches, answered queries, unanswered queries, and feedback are only updated for the language in which each interaction occurred.
</Expandable>

<Expandable title="How does Eddy AI conversation analytics work when a conversation spans multiple workspaces?">
  The conversation is recorded in the conversations table for each workspace used. Specific metrics such as total searches, answered queries, unanswered queries, and feedback are only updated for the languages used within the respective workspace.
</Expandable>

<Expandable title="How are queries different from conversations?">
  A query is an individual question asked to Eddy AI. A conversation is a session that contains one or more queries. For example, a reader asking three follow-up questions in a single session counts as one conversation with three queries.
</Expandable>

<Expandable title="Why don't I see the Try new Eddy AI analytics option?">
  Availability depends on your plan, and the feature must be enabled for your project. Also confirm that you have analytics access — you need admin or owner access, or a custom role with view analytics permission. To check availability for your project, contact your Customer Success Manager or [Document360 support](mailto:support@document360.com).
</Expandable>

<Expandable title="Why do the tiles on the advanced analytics page show 0 when the tables below show data?">
  The tiles and charts on the advanced analytics page refresh periodically, while the tables read the latest processed data. If the tiles show 0 and the tables show results, the tile values have not refreshed yet. Check again later in the day.
</Expandable>

<Expandable title="Can I open the advanced analytics page directly using its URL?">
  No. Open the advanced analytics page from the **Try new Eddy AI analytics** option on the **Eddy AI - Assistive Search** analytics page each time. Entering the URL directly or refreshing the page in your browser returns you to the **Eddy AI - Assistive Search** analytics page.
</Expandable>
