This theme provides a `@theme/Mermaid` component that is powered by [mermaid](https://mermaid-js.github.io/). You can read more on [diagrams](/docs/3-0-1/markdown-features/diagrams) documentation.

<Tabs>
  <Tab title="npm">
    ```bash
    npm install --save @docusaurus/theme-mermaid
    ```
  </Tab>

  <Tab title="Yarn">
    ```bash
    yarn add @docusaurus/theme-mermaid
    ```
  </Tab>

  <Tab title="pnpm">
    ```bash
    pnpm add @docusaurus/theme-mermaid
    ```
  </Tab>

  <Tab title="Bun">
    ```bash
    bun add @docusaurus/theme-mermaid
    ```
  </Tab>
</Tabs>

## Configuration

```js title="docusaurus.config.js"
export default {
  themes: ['@docusaurus/theme-mermaid'],
  // In order for Mermaid code blocks in Markdown to work,
  // you also need to enable the Remark plugin with this option
  markdown: {
    mermaid: true,
  },
};
```
