Congratulations! You have understood most core features of Docusaurus now. You have:

- [Used the pages plugin](/docs/3-0-1/creating-pages) to create a standalone React / Markdown page
- [Used the docs plugin](/docs/3-0-1/docs-introduction) to create documentation pages. This includes [configuring the sidebar](/docs/3-0-1/sidebar), and even [versioning](/docs/3-0-1/versioning)
- [Used the blog plugin](/docs/3-0-1/blog) to create a fully featured blog
- Tried your hands on [a range of Markdown features](/docs/3-0-1/markdown-features), which are useful for all content plugins
- [Used stylesheets](/docs/3-0-1/styling-layout) or [swizzling](/docs/3-0-1/swizzling) to customize your site's appearance
- [Included images and other assets](/docs/3-0-1/static-assets) in your pages
- [Added search](/docs/3-0-1/search) to your site
- Understood how [browser support](/docs/3-0-1/browser-support) and [SEO](/docs/3-0-1/seo) are done through standard Docusaurus APIs
- Learned about how [individual plugins](/docs/3-0-1/using-plugins) are installed and configured
- [Deployed](/docs/3-0-1/deployment) your site to a content host
- [Internationalized](/docs/3-0-1/i18n/tutorial) your site to include multiple languages

At this point, you probably have a big `docusaurus.config.js` already😄 However, you haven't written much code yet! Most of the features are implemented through calling encapsulated Docusaurus APIs. As you continue your journey, you can take three paths:

- Learn more advanced Docusaurus concepts. This will help you gain a deeper understand of what the APIs do.
- Read about [all existing APIs](/docs/3-0-1/docusaurus-core). Many of them have not been covered in the Guides!
- Learn to [develop a plugin](/docs/3-0-1/api/plugin-methods) to extend the functionality of your site.
