With live edits enabled, members in your org can edit a section without creating [a change request](/docs/collaborate/change-requests). When editing content, you can see the avatars of anyone currently viewing the section in the top-right corner.

GitBook supports live collaboration, meaning you’ll be able to work on the same document with multiple members at the same time.

<Callout kind="info">
  **Live edits are locked** by default in any newly created section. To edit the content, you will either need to [create a change request](/docs/collaborate/change-requests), or toggle live edits on.
</Callout>

### Toggling live edit mode

You can toggle live edit mode in a section by clicking **Lock live edits** or **Unlock live edits** in the [section header’s](/docs/reference/gitbook-ui#space-header) **Actions menu** <Image src="https://blob-cdn.documentation.ai/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793686680250-b01qn5scaep-spaces-2FNkEGS7hzeqa35sMXQZ4X-2Fuploads-2FPnnI41SqLSaKBNwT98fW-2Factions-horizontal.svg?rasterize-bypass=true" alt="The Actions menu icon in GitBook" />.

When a section is in **Live edits** mode, the section header will show the **Editor** tab. When it is in **Locked live edits** mode, the section header will show a **Read-only** tab. When the Read-only tab appears in the section header, you will need to open a change request to edit the content of the page, or unlock live edits.

### When is live editing *not* available?

You cannot unlock live editing if:

1. a section is published with the **Public** or **Unlisted** visibility option.
2. a section has [GitHub or GitLab Sync](/docs/docs-as-code/git-sync) enabled.

<Callout kind="info">
  Only [administrators and creators](/docs/collaborate/member-management/roles) can lock or unlock live edits.
</Callout>
