Creating interactive decision trees in Document360 helps you map out clear, sequential steps to simplify tasks for users. This guide shows you how to create interactive decision trees in Document360 using blank canvases or templates. Learn to add steps, media, and actions for an engaging user experience.

## Create a new Interactive decision tree

1. Log-in to the Knowledge base portal and select your project.
2. Select **Interactive decision tree** () from the left navigation bar.
3. Click the **Create** button from the header menu and select **Interactive decision tree**. This will open the **Create a new interactive decision tree** panel.

4. In the **Create a new interactive decision tree** panel, enter a name in the **Title** field and select a category from the **Category** dropdown menu.
5. Click **Create**.

 NOTE

The system automatically creates a default category titled "Interactive Decision Trees" before you create your first decision tree, unless you create one yourself.

Once you have created your interactive decision tree, you can start adding steps. You can either select a [pre-built template](/docs/creating-interactive-decision-trees#creating-an-interactive-decision-tree-from-a-template) or start from a [blank canvas](/docs/creating-interactive-decision-trees#creating-an-interactive-decision-tree-from-a-blank-canvas).

### Creating an interactive decision tree from a blank canvas

To add steps to your decision tree from a blank canvas,

1. Click <strong>+Add your first step</strong>. This will open a panel where you can select your content layout and add your step details.
2. Click the **Layout** dropdown in the top-left corner of the panel to display the available layouts and alignment options. The available layouts include:

   - **Content-only layouts**: Ideal for text-focused steps.
   - **Mixed layouts**: Combine text and visuals side-by-side.
   - **Visual-first layouts**: Highlight images or media with supporting text.
3. Use the **Alignment** options (left, center, or right) to position your content within the selected layout.

<Image src="https://test-dai.imgix.net/org-305180ff-8bbf-40a5-bdbf-7db82ff17465/doc-37e0ac78-8ede-48d7-8b5d-fcbc080a78a6/1793778349596-237og9ors8l-create-20from-20blank-20canvas.png?fm=auto&auto=compress%2Cformat" alt="" />

4. Enter a title for your step. This will be visible in the visual editor in the knowledge base portal.
5. Next, enter a description for your step. You can add any relevant information here. You can access formatting and insert options using the `/` command.

    NOTE

   You can access all key editor functions using the slash command, with the exception of Page break, File, Private note, and Content reuse elements (Glossary, Snippets, Variables), which aren't supported at this time.

#### Adding Media

To add media to your step,

1. Click **Add image** in the media section of the layout.
2. Upload an image from your local drive or select from your previously uploaded media from **Drive**.
3. Adjust the placement of the media within the layout to ensure it complements the text content.

The media section accepts images only. To add a video, type `/` in the step body and select **Insert** > **Video**, then choose **Embed URL**, **Embed code**, or **Drive**.

#### Adding Actions

To include actions in your step,

1. Click <strong>\+ Action</strong> to open the action type dropdown.
2. Select an action type from the available options:

   - **Buttons**: Add navigation buttons for the next or previous step in the decision tree.
   - **Radio Choices**: Present multiple-choice options for users to select one.
   - **Dropdown Choices**: Provide a dropdown menu for users to pick from predefined options.
3. Configure the action's behavior, such as linking to a new or existing step, external URL, or an existing Interactive decision tree.
4. Save the action to include it in the step.
5. If you have multiple steps added to your decision tree, you can quickly switch to a different step and make any edits using the **Jump to** option.
6. Click **Done** to add the step to your decision tree. Repeat these steps to continue building your interactive decision tree with additional steps.
7. Once you are done creating all the required steps, click **Publish** to make the Interactive decision tree live.

 NOTE

You can use the drag-and-drop functionality in the visual editor to link one step to another. This allows you to create a logical flow between steps, enhancing the decision tree's usability and navigation.

### Creating an interactive decision tree from a template

To create an interactive decision tree using a pre-built template,

1. Select a template from the list of templates displayed on the screen. Templates include options like a 3-step onboarding Interactive decision tree or a 2-step Interactive decision tree without media.
2. Review the template structure. Templates come with pre-defined steps and layouts to help you get started quickly.
3. Click on a step to edit its title, content, or media. Use the following features as needed:

   - **Adding media**: Click **Add image**, upload an image, and adjust placement to align with the step content. To add a video, type `/` in the step body and select **Insert** > **Video**.
   - **Adding actions**: Click <strong>\+ Action</strong> to include buttons, dropdowns, or other interactive elements. Configure the behavior for each action.

      NOTE

     Click **Preview** before finalizing the step to view it in the knowledge base site.
4. Click **Preview** in the article header to view the entire decision tree in the knowledge base site from a reader's perspective.
5. When satisfied, click **Publish** to make the Interactive decision tree live.

 NOTE

You can use the drag-and-drop functionality in the visual editor to link one step to another. This allows you to create a logical flow between steps, enhancing the decision tree's usability and navigation.

## FAQ

<Expandable title="What are the supported file types when adding media to Interactive decision trees?">
  The media section (**Add image**) supports **JPG**, **JPEG**, **PNG**, **SVG**, and **BMP** images. To add a video, type `/` in the step body and select **Insert** > **Video**. You can use **Embed URL** (a self-hosted URL ending in .mp4, or an embed URL), **Embed code**, or **Drive**.
</Expandable>

<Expandable title="Are there any restrictions for images and videos uploaded to Interactive decision trees?">
  The media section accepts images up to **150 MB**. For optimal performance, keep images under **5MB** and videos under **20MB**. The recommended resolution for videos is **1920x1080**, and the recommended resolution for images is **1080x720**.
</Expandable>

<Expandable title="Can I add actions directly from the visual editor?">
  Yes, you can add actions directly from the visual editor by clicking the <strong>\+ Action</strong> button below a step. Choose an action type from the dropdown options, such as buttons, radio choices, checkbox choices, or dropdown choices. Once selected, configure the behavior of the action and save it within the step.
</Expandable>

<Expandable title="Why do I see a warning about unconnected actions when publishing an Interactive decision tree?">
  If you see a warning stating, "You've got unconnected actions," it means some steps contain actions (e.g., buttons or dropdowns) that are not linked to other steps or destinations. While this warning does not prevent you from publishing the decision tree, it serves as a reminder to review and confirm that all actions are appropriately connected. Unconnected actions may disrupt the flow and impact the usability of the decision tree.
</Expandable>

<Expandable title="Are Interactive decision trees mobile-friendly?">
  Yes, decision trees are fully responsive and optimized for viewing on mobile devices, though layout choices may affect how content is displayed.
</Expandable>
