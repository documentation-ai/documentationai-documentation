To format your text, simply select the words you want and choose one of the formats from the context menu — or format your text using a keyboard shortcut or through Markdown syntax.

<Callout kind="info">
  We've written these shortcuts using Mac keys. Use **Control** in place of <strong>⌘ (Command)</strong> on Windows or Linux operating systems. Check out our keyboard shortcuts section to see all the shortcuts for all operating systems.
</Callout>

#### Bold

Keyboard shortcut: <kbd>⌘</kbd> \+ <kbd>B</kbd>

<Tabs>
  <Tab title="Markdown">
    ```markdown
    **Bold**
    ```
  </Tab>
</Tabs>

#### Italic

Keyboard shortcut : <kbd>⌘</kbd> \+ <kbd>I</kbd>

<Tabs>
  <Tab title="Markdown">
    ```markdown
    _Italic_
    ```
  </Tab>
</Tabs>

#### Strikethrough

Keyboard shortcut: <kbd>⇧</kbd> \+ <kbd>⌘</kbd> \+ <kbd>S</kbd>

<Tabs>
  <Tab title="Markdown">
    ```markdown
    ~~Strikethrough~~
    ```
  </Tab>
</Tabs>

#### Code

Keyboard shortcut: <kbd>⌘</kbd> \+ <kbd>E</kbd>

<Tabs>
  <Tab title="Markdown">
    ```markdown
    `Code`
    ```
  </Tab>
</Tabs>

#### Link

Keyboard shortcut: <kbd>⌘</kbd> \+ <kbd>K</kbd>

When you add a link to text on your page, you'll be prompted to provide the link. You can add any URL, but if you're linking to another page or section in your site, we recommend using a relative link.

#### Color and background color

Click the color icon in the context menu, and choose a color for the text or its background.

### Right-to-left text

GitBook doesn't currently support right-to-left contributions. Paragraphs and headings automatically detect RTL text and adapt their layout, but lists and other content blocks may not align properly, and font quality can be reduced for some languages.
