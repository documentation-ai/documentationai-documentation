## Integration formula

The integral of a function is its antiderivative: $\int f(x)\,dx = F(x) + C$, where $F'(x) = f(x)$.

$$
\int x^{n}\,dx = \frac{x^{n+1}}{n+1} + C \quad \text{for } n \neq -1
$$

The same rule works for any equation once each term is integrated term by term.

$$
\int \left(3x^{2} - 4x + 5\right) dx = x^{3} - 2x^{2} + 5x + C
$$
